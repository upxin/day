# 《长生海》V10账本：初赋供需与知情层级

## 一、四层公开与权限边界

### 1. 普通公众知道什么

- “新生生命底图校准”真实、合法，能建立儿童终身医疗模型。
- 校准中可在家庭明确授权下分离约30%的“初赋”，制成一份标准稳态制剂。
- 同一份制剂有两种公开用途：完成一次严重疾病复稳，或使一名健康成年人维持约一年的生理年龄；两种用途消耗等量。
- 社会知道停龄必须按年续用，也知道资格主要分配给政务、科研、军事、医疗与星际工程岗位。围绕“谁不可替代”“孩子能否由父母代为授权”的争论从制度诞生时就存在。
- 六年公开随访中，最初100名标准供体儿童没有出现可归因的严重伤害；技术因此不是靠伪造或秘密才被接受。
- 家庭可以拒绝标准提取；六年附条件放行以后，产科普遍主动询问，医疗保障、教育与住房补偿以及战后互助伦理共同把峰值覆盖推至八成。制度利用了选择压力，但没有靠一纸强制令解决全部授权。

公众无法完全知道的是：每名受体身份、各方真实储备、2130年以前为阿卡迪亚任务预留的仓位、私人质押仓、黑市流量，以及某个孩子最终对应哪只容器。各方会公布区域提取率和战略储备区间，因此核心用途与大体规模都不隐瞒；隐蔽的是申报区间之外的边缘、具体流向和责任链。2130年改定任务以后，阿卡迪亚只获准携带一批公开登记、用途锁定的旧库存，用于少数无法全程低温的任务成员与紧急复稳；它不能覆盖全部患者，也不能自动延续到返航终点。

### 2. 医疗与供应系统知道什么

- 产科知道校准类别和设备是否完成分离，但多数岗位看不到最终用途。
- 治疗与停龄机构都知道本院适应症、受体资格和配额，但多数岗位看不到跨区总量。
- 冷链人员只看见容器等级、效价、去向代码和保存要求。
- 生产区、受体医院、身份管理与运输分别由不同机构负责；每个环节都能合法完成自己的工作，却无法单独拼出某个供体的完整去向。

因此后期的谜团不是“续生是否存在”，而是公开总量之外究竟多提取了多少、去了哪里，以及为何一批官方标记为“未提取”的人也患上白潮。

### 3. 六方核心层知道什么

- 标准制剂用于疾病时能够完成一次复稳疗程；用于健康成年人时，则能让其停留在开始用药时的生理年龄约一年，之后必须重新使用一份等量制剂。
- 停龄资格与年度总配额公开运行，只向极少数政务、科研、军事、医疗和星际工程岗位开放；具体姓名、健康状态与各方储备仍受隐私法和战略条例保护。
- 核心层知道供体长期风险仍未验证，也知道扩大时只有100名儿童完成六年随访；他们不知道典型白潮会把未经复稳或低温干预者推向三十六周岁的年龄墙。
- 各方都建立自己的储备，彼此不肯相信对方会在战争、灾难或政权更替时继续供应。

### 4. 三本账为什么长期无法互证

公开治疗需要不断供，公开停龄需要年度续针，六方各自要求战略储备，阿卡迪亚工程也曾要求提前锁定长期医疗安全量。出于隐私、战略安全、战后互不信任和正常的职责分离，同一条供应链在制度建立之初便被拆成三本都真实的账：

1. **公共医疗账：** 校准人数、标准制剂产出、疾病治疗、贫困救助、灾难储备、正常工艺损耗；
2. **连续性用药账：** 使用同一标准制剂的停龄受体、年度义务、关键岗位等级、各方安全冗余；总配额公开，个人键与分仓细目受限；
3. **实体冷链账：** 每只容器真实存在的位置、效价、能耗、保质期与转运记录。

三本账分别接受不同机构审计。能够把“哪一个孩子—哪一只容器—哪一个成年人”重新连起来的交叉映射需要六方联合授权，不由任何一个人天然掌握。这套制度有一个根本遗漏：

> 当年账能平，是因为供体只被列作来源，还没有被列作三十六周岁时的患者。

雷蒙后来利用分账边界拖延跨区因果统计、把超额储备转成私人权力，并让黑市进入合法冷链。这些是清楚、可举证、可以由一个人承担刑责的恶；但即使删去雷蒙，短期救治、年度依赖、六方互疑和阿卡迪亚早期储备需求仍会推动悲剧发生。

真相公开后，六方选择以雷蒙完成政治意义上的“平账”：他的罪证最完整、行为最主动，也最适合被从制度中切除。雷蒙被捕、受审，私人仓与资产被没收；其余签字者大多只承担停职、退休、听证或道德责任。处罚雷蒙并没有偿还供体，只让制度能够宣布“犯罪已经被清除”。

## 二、剂量与产出规则

| 项目 | 净分离量 | 成人用途 | 新生供体结果 | 公开程度 |
|---|---:|---|---|---|
| 生命底图读取 | 低于1%且完整回输 | 诊断与终身模型 | 接近自然背景 | 完全公开 |
| 标准初赋制剂 | 约30% | 治疗一次严重疾病，或使健康成年人停龄约一年；两种用途消耗等量 | 童年与青年期大多正常，约55%—70%在成年稳态重索引时进入白潮；未经复稳或低温干预者在36周岁这一生理年终末崩解 | 两种用途均公开 |
| 外星警戒区 | 超过40% | 没有可靠的额外疗效 | 出生期开始出现循环、发育和神经小异常 | 专业资料可查 |
| 外星死亡线 | 超过50% | 没有可靠的额外疗效 | 急性崩溃与死亡概率陡升 | 专业资料可查 |

- 人类没有设计治疗量与停龄量两套药。外星资料给出的是同一条提取曲线；人类为远离40%警戒区和50%死亡线，把30%定为唯一标准量。
- **机制只按这一段执行：** 初赋的物质本体是“新生期全身稳态囊泡复合群”，即一群具有物种与个体表面标记、共同携带调控RNA、短肽、脂质和代谢辅因子的纳米级胞外囊泡。任何单一成分都不能独立生效。胎儿脱离母体后，极少量尚未嵌入身体的囊泡会在血液中游离约十小时，并被新生儿的器官、免疫、神经、代谢与修复系统迅速吸收。设备只能通过体外闭合循环截留仍在血液中游离的部分，运行时长决定截留比例；囊泡进入组织后随即解体并写入细胞，无法重新提取为有效制剂。十小时后游离池关闭，采血、干细胞培养和器官处理都只能得到失去连续拓扑的碎片。30%以这段可分离游离池为分母，不是婴儿血容量；正文不为最终活性物规定精确毫升数。
- 治病与停龄的区别不在剂量：治病通常在完成一次或少数疗程后结束，停龄则每年自动产生一份新的等量需求。
- 一名新生供体形成一份标准制剂。上一年度制剂降解后，下一年可以使用另一名供体的制剂，不存在终身认主，也不需要解释多供体拼接。
- 初赋可以长期低温保存；地球验证的可靠效价期为35—50年，之后逐年衰减。它可以形成几十年的库存与金融权力，但不是永不贬值的无限仓库。
- 成年受体连续使用一至三次后停用，通常只出现可逆的免疫与代谢震荡，仍可回到自然衰老；连续使用五年以上往往形成强依赖，骤停可能导致快速失稳、衰老、记忆边界混乱和人格冲突样症状。撤药伤害不能替任何人的占有、暴力或制度选择免责。
- 人工合成只能复制初赋中的局部信号，不能重建连续原生拓扑。人工子宫可以让胎儿存活，但缺少完整、动态的母体免疫—内分泌—微生物—神经节律耦合，出生时形成的初赋平均质量更低、连续性更差，既不能成为稳定工业药源，也不能替代自然妊娠完成新生自续的人类验证。

## 三、人口与年度流量区间

### 1. 世界基数

- 三战后重建稳定期总人口：约1.4亿—1.8亿。
- 年出生人口：约65万—85万。
- 人口不是持续高速增长；战后创伤、城市化、长教育期与远航社会使生育率长期偏低。

### 2. 公开治疗需求与实际获配

- 2094—2100年：辐射相关癌症与免疫病仍处高峰，潜在年需求约18万—30万份；六年人体计划只提供100份标准制剂，绝大多数患者仍得不到。
- 2100—2118年：附条件放行后，潜在年治疗需求约14万—22万份，并推动产能迅速扩张；受产出、适应症和储备锁定限制，实际年获配约6万—10万份。
- 2119—2129年：常规医学继续进步，潜在年需求约10万—18万份，实际年获配约5万—8万份。
- 2130—2136年：六方承认因果后采取不同临时办法。暂停区主要调用旧库存，重症例外区仍允许少量新增，过渡区维持关键岗位用量，另有无法解释的失踪批次；可核实的实际年获配总体降至约3万—5万份，但不能写成全球统一停抽。

早期实际治疗量始终大于同期停龄人数。公众看见的繁荣不是假景：大量初赋医疗在眼前确实用于治病。可是潜在需求从未全部满足，疾病疗程会结束，停龄承诺却不会自行结束。后文核算一律使用“实际获配量”，不能把潜在需求直接当成已经消耗的制剂。

### 3. 年度停龄人数

| 时间 | 活跃年度依赖者 | 制度状态 |
|---|---:|---|
| 2094—2100年 | 4—6人 | 六年试验；依靠预存的100份制剂连续观察 |
| 2101年 | 100—300人 | 特别法下首批公开限定队列 |
| 2106年 | 5000—1万人 | 指数扩张后资格名单膨胀 |
| 2112年 | 3万—5万 | 六方关键岗位与工程名单膨胀 |
| 2118年 | 8万—12万 | 继任失效，年度义务固化 |
| 2130年 | 14万—18万人 | 年龄墙公开；六方开始执行彼此不同的暂停、旧库存和过渡规则 |
| 2136年 | 12万—16万人 | 减量、断供死亡、地区例外与私仓延续并存；地球仍未形成统一永久答案 |

这批人不足总人口的0.15%，却每年形成新的刚性义务。公开治疗会随病人康复结束，停龄则只要受体活着，下一年就自动再次到期。

### 4. 标准提取覆盖率

| 时间 | 全球新生儿标准30%提取比例 | 说明 |
|---|---:|---|
| 2094年 | 100名，共一次入组 | 六年内不新增人体供体；100份制剂覆盖疾病组与极少数连续停龄者 |
| 2100年（第七年） | 2千—5千名 | 附条件许可后的第一次数量级跃升；王远等人出生；少数示范区内可达约80% |
| 2101年（第八年） | 2万—5万名 | 产科分离模块快速复制 |
| 2102—2103年 | 8万—30万名／年 | 从试点转为产业，仍处指数增长段 |
| 2104年 | 20万—40万名 | 指数段末端，开始受出生人口与产科容量约束 |
| 2105—2108年 | 40%—60% | 增长开始受出生人口与产科容量约束 |
| 2109—2116年 | 70%—80% | 八年平台峰值；“八成一代”的严格含义 |
| 2117—2122年 | 55%—70% | 仓储渐满、社会拒绝上升 |
| 2123—2128年 | 30%—50% | 最初100名供体出现零星异常，官方收缩，黑市占比上升 |
| 2129年 | 10%—25% | 最初100人接近年龄墙，合法项目紧急复核 |
| 2130—2136年 | 无统一全球比例 | 六方分别暂停、调用旧库存、保留重症例外或维持关键岗位过渡；公开提取锐减，但失踪批次使真实下限无法确认 |

“指数增长”只描述2100—2103年的早期产业复制，随后必然转成受出生人口约束的S形曲线。“80%”不是整整二十多年全球恒定抽取，也不是80%世界人口；它指黄金扩张峰值年份出生的一代。

危机后的第一次联合追溯给出：单年峰值约60万—65万名新生供体，约占当年出生人口的75%—80%；合法记录、重复登记、黑市与无法反查部分合并后，扩张期实际供体约850万—1000万。按55%—70%的终身发病率估算，预期白潮患者约470万—700万。正文在制度崩溃以前不反复播报这个完整数字，只展示局部繁荣和“越来越多”。

这不等于扩张规模被整体隐瞒。六方每年都公布各自的入组、产出和储备数字，只是统计口径不同、跨区转运重复计数、私人仓不入公共口径、黑市没有身份键，因此公众知道它已经极其庞大，却无法得到一个可信的全球去重总数。危机后的60万—65万是第一次联合追溯值，不是第一次有人承认采集存在。

## 四、为什么会抽得远多于当年实际用量

停龄依赖者即使到2136年只有十几万，也能推动数百万库存形成，原因不是单一消费，而是四次重复计算：

1. 六方各自按最坏断供情形建立10—15年战略仓，拒绝共享全部底数；
2. 阿卡迪亚曾按原定任务锁定长期医疗与关键人员储备，2130年任务改定后，大部分实物留在地球处置；只有用途锁定、全程登记的少量旧库存随船；
3. 医院必须保留公开治疗安全库存，不能在账面上被停龄计划直接调用；
4. 私人仓、黑市和金融质押把“未来可以使用”本身变成资产。

六方依靠新生人口持续增长，才让这些互相冲突的承诺在每一年度都显示为“已覆盖”。这不是某个会计师算错，而是整个制度默认下一年度仍会有新的孩子提供增量。

2136年前后，全球仍可物理确认的标准制剂库存约为200万—300万个当量，但它被分仓、冻结、质押、查封并处在六套临时规则下，质量等级也不一致。按累计850万—1000万份产出核算：约200万—300万份用于疾病复稳，约250万—320万份用于历年停龄，约50万—100万份在损耗、失效、事故与无法确认流向中消失，余下部分形成现存库存。阿卡迪亚携带量只占现存库存极小部分，并受任务章程逐份锁定。**库存总量充足，不等于某个患者拥有调用权，更不等于地球已经决定怎样使用它。**

## 五、试验与白潮时间账

- 2094年按10名哨兵、30名扩展、60名确认三段纳入100名新生供体，所有供体都按30%标准量提取；100份制剂同时覆盖一次性疾病复稳与4—6名成年人的连续停龄观察，随后六年不新增人体供体。
- 2100年总结时，100名供体已经随访六年，所有传统指标仍然正常。制度没有借用另一剂量的数据，也没有伪造结果；它只是把六年真实安全外推到三十六岁以后。
- 2100年第七年进入数千人规模，2101年第八年进入数万人规模，随后在四至五年内升至数十万并触及出生人口平台。
- 2124年前后，最初100名供体接近三十岁并出现分散异常；2129年他们三十五岁，多个系统同时接近临床阈值；2130年进入三十六周岁后，约55%—70%在同一出生年度转入典型白潮。凡进入典型白潮又未获得复稳或低温干预者，都会在三十六周岁这一生理年进入终末多器官崩解；早发症状只改变病程长短，不改变成年稳态重索引的终点。公开终身随访因此不再可能把病例拆散解释。
- 第七年扩张队列出生于2100年，在首批年龄墙公开时正好三十岁，到2136年抵达三十六岁。危机由两部分组成：100名首批供体已经证明的结局，以及数百万后来者提前知道自己将在什么年龄靠近同一道墙。

长生海的**固定设计容量为2000万人**。这个数字不是“已经发病人数”，而是对整个校准时代不确定性的工程回应：

- 2136年前后确诊、已经死亡或进入重症临床的患者约10万—30万；
- 已确认或能高度推定接受过标准提取、但尚未发病者约700万—850万；
- 出生记录缺失、类别授权含混、黑市或承包链无法反查，因而无法排除曾被提取的人约800万—1000万；
- 三类按最终安置身份互斥统计。并非所有不确定者都选择低温；到2136年获准并实际进入低温者约110万—140万，主要来自2094年试验队列、2100—2106年前期扩张队列及少量明确早发者。更年轻的黄金扩张代大多仍在登记、监测、预留舱位或等待以后申请。两千万是面向此后连续年龄墙的长期设计容量，不是发射时必须填满的数字。

工程从2130年因果承认后便开始把战时地下掩体、轨道货运井、废弃数据中心和沿海能源站改造成低温区，2131年由第一批改造区接收已出现症状或已确认高风险、又不愿等待临床发作的人。舱体采用低代谢玻璃化、分区聚变供能、储能冗余与失电后的被动隔热维持，不是每一座舱都配一套独立医院；自动化工厂以相同接口滚动制造，旧基础设施提供体量。低温不是终末抢救：一旦神经与多器官损伤进入不可逆区，冷冻只能保存损伤。因此高风险者通常在三十至三十一岁进入首批低温，而不是等到三十五六岁。到发射时已经连续建设六年，长期总规划固定为2000万设计位但仍在扩建，实际启用约110万—140万；后续空间与接口是为尚未抵达建议入舱年龄的后来队列预建。电网、制冷剂、维护劳动与地区优先级必须在正文中成为持续冲突，不能把长生海写成免费的背景设施。

这使长生海真正成为一片改变人口结构的黑色大陆，又不要求两千万人已经同时病倒：许多人是在没有可靠个体预测手段、也不敢等到三十六岁才决定时，主动把自己从公共时间里移走；另一些人拒绝低温或继续观望，社会反应不能写成整齐一致。

## 六、白潮因果为什么只能由制度自己承认

早期怀疑者并非没有查：医生看见病例，家庭回忆设备与针孔，审计员发现实体产出大于公开治疗、停龄和申报储备之和，媒体追问为何“未提取者”也发病。问题在于他们拿到的都只是局部真相。

- 公共医疗与停龄总配额可以解释大部分出生分离量；
- 连续性用药账以隐私和战略安全拒绝公开个人交叉键；
- 实体冷链账只有容器，没有供体与受体身份；
- 黑市原本就没有完整身份记录；
- 白潮早期又能被分散诊断解释。

白雪曾短暂接近三账交叉处。她发现实体产出在扣除公开治疗、停龄配额与申报储备上限以后仍持续多出约3%—6%；这个比例高于理想损耗，却落在跨区重复登记、效价折损和工艺报废可以联合声称覆盖的灰区，每本账在各自审计范围内仍能成立。若强行申请六方交叉，会同时冻结公开治疗、续生配额、阿卡迪亚储备与大量家庭随访。因果尚未成立时，她接受降级，选择继续留在制度内审计，并在后来成为年度受益者。这是她独立于“驳回弱关联申请”的另一重原罪。

真正的公开发生在2130年前后以下事实同时出现以后：

1. 最初100名标准供体在三十六周岁形成无法由分科诊断解释的年龄墙，发病率越过统计红线；
2. 在相同出生年、示范区与病程定义内，有明确标准提取记录者的发病率稳定高于未提取对照，剂量与成年病程形成无法再由其他疾病解释的曲线；
3. 实体库存量远超公开治疗、公开停龄与申报灾难储备所需；
4. 多方各自掌握的数据已经可以在制度之外互相校验；
5. 继续否认会使全部医疗记录失去公信力，并诱发产科拒绝与冷链失控。

于是六方不是被一名英雄“曝光”，而是在再也无法维持医疗秩序时联合承认：合法的30%标准提取本身会在一代人后造成白潮，超额库存和非法流量又把受害范围推得比官方名册更大。它们只开放部分交叉账，却没有形成统一永久禁令：有的暂停新增，有的只准旧库存，有的保留重症例外，有的维持等待C-9以前的关键岗位过渡，还有公开收紧却留下失踪批次者。白雪参加文本起草和签署，迫使公告写入标准制度责任、自己的年度用药与当年降级决定；她改变了承认的完整程度，却不能把自己写成发现一切、拯救一切的泄密者。

承认之后，官方叙事迅速把“合法制度造成的一代伤害”改写成“雷蒙利用制度漏洞实施的系统性犯罪”。这句话并非全假：雷蒙确实有罪；它真正遮住的是，没有他的那些年份，合法提取同样每天发生。

## 七、正文数字纪律

- 正文可写“数十万”“近千万”“两千万设计位”“不足千分之二”，避免每章报表；“长生海两千万”是允许反复出现的固定意象数字。
- “八成”只用于峰值出生代或特定覆盖区，不用于全部历史人口。
- 治病与年度停龄两种用途从人体试验起就公开；后期不得再把“发现续生存在”写成悬疑。
- 实体产出大于公开治疗、停龄与申报储备之和，只负责指向超额囤积和利益问题；白潮因果则由明确供体与未提取对照的长期病程差异证明。两条证据彼此加强，但不依赖丢失记录制造悬疑。
- 任何人说“药明明够”时，都要回答的是调用权、质量、仓属与下一年度义务，而不是只回答物理总量。
- “雷蒙平账”只能指危机后以处罚一个明面恶人结清集体责任，不能再写成他负责设计三本账或维持全系统运行。
