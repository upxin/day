# 《长生海》V10账本：初赋供需与知情层级

> **版本状态：现行数量正典。** 这是总纲与章节目录的校验表，不是正文里的完整公开文件。正文可以模糊数字，但不得与本账本的数量级、时间先后和知情边界冲突。

## 一、四层公开与权限边界

### 1. 普通公众知道什么

- “新生生命底图校准”真实、合法，能建立儿童终身医疗模型。
- 校准中可在家庭明确授权下分离约30%的“初赋”，制成一份标准稳态制剂。
- 同一份制剂有两种公开用途：完成一次严重疾病复稳，或使一名健康成年人维持约一年的生理年龄；两种用途消耗等量。
- 社会知道停龄必须按年续用，也知道资格主要分配给政务、科研、军事、医疗与星际工程岗位。围绕“谁不可替代”“孩子能否由父母代为授权”的争论从制度诞生时就存在。
- 十年公开随访中，接受标准提取的供体儿童没有出现可归因的严重伤害；技术因此不是靠伪造或秘密才被接受。
- 家庭可以拒绝标准提取；十年安全以后，产科普遍主动询问，医疗保障、教育与住房补偿以及战后互助伦理共同把峰值覆盖推至八成。制度利用了选择压力，但没有靠一纸强制令解决全部授权。

公众无法完全知道的是：每名受体身份、各方真实储备、阿卡迪亚专仓、私人质押仓、黑市流量，以及某个孩子最终对应哪只容器。核心用途不隐瞒，隐蔽的是规模边缘、具体流向和责任链。

### 2. 医疗与供应系统知道什么

- 产科知道校准类别和设备是否完成分离，但多数岗位看不到最终用途。
- 治疗与停龄机构都知道本院适应症、受体资格和配额，但多数岗位看不到跨区总量。
- 冷链人员只看见容器等级、效价、去向代码和保存要求。
- 生产区、受体医院、身份管理与运输分别由不同机构负责；每个环节都能合法完成自己的工作，却无法单独拼出某个供体的完整去向。

因此后期的谜团不是“续生是否存在”，而是公开总量之外究竟多提取了多少、去了哪里，以及为何一批官方标记为“未提取”的人也患上白潮。

### 3. 六方核心层知道什么

- 标准制剂用于疾病时能够完成一次复稳疗程；用于健康成年人时，则能让其停留在开始用药时的生理年龄约一年，之后必须重新使用一份等量制剂。
- 停龄资格与年度总配额公开运行，只向极少数政务、科研、军事、医疗和星际工程岗位开放；具体姓名、健康状态与各方储备仍受隐私法和战略条例保护。
- 核心层知道供体长期风险仍未验证，也知道扩大时最长的人体随访只有十年；他们不知道白潮将在三十至四十岁集中爆发。
- 各方都建立自己的储备，彼此不肯相信对方会在战争、灾难或政权更替时继续供应。

### 4. 三本账为什么长期无法互证

公开治疗需要不断供，公开停龄需要年度续针，六方各自要求战略储备，阿卡迪亚又要求把几十年的医疗安全量提前锁进船仓。出于隐私、战略安全、战后互不信任和正常的职责分离，同一条供应链在制度建立之初便被拆成三本都真实的账：

1. **公共医疗账：** 校准人数、标准制剂产出、疾病治疗、贫困救助、灾难储备、正常工艺损耗；
2. **连续性用药账：** 使用同一标准制剂的停龄受体、年度义务、关键岗位等级、各方安全冗余；总配额公开，个人键与分仓细目受限；
3. **实体冷链账：** 每只容器真实存在的位置、效价、能耗、保质期与转运记录。

三本账分别接受不同机构审计。能够把“哪一个孩子—哪一只容器—哪一个成年人”重新连起来的交叉映射需要六方联合授权，不由任何一个人天然掌握。这套制度有一个根本遗漏：

> 当年账能平，是因为供体只被列作来源，还没有被列作三十五年后的患者。

雷蒙后来利用分账边界故意拆散反向键、把超额储备转成私人权力，并让黑市进入合法冷链。这些是清楚、可举证、可以由一个人承担刑责的恶；但即使删去雷蒙，短期救治、年度依赖、六方互疑和阿卡迪亚储备仍会推动悲剧发生。

真相公开后，六方选择以雷蒙完成政治意义上的“平账”：他的罪证最完整、行为最主动，也最适合被从制度中切除。雷蒙被捕、受审，私人仓与资产被没收；其余签字者大多只承担停职、退休、听证或道德责任。处罚雷蒙并没有偿还供体，只让制度能够宣布“犯罪已经被清除”。

## 二、剂量与产出规则

| 项目 | 净分离量 | 成人用途 | 新生供体结果 | 公开程度 |
|---|---:|---|---|---|
| 生命底图读取 | 低于1%且完整回输 | 诊断与终身模型 | 接近自然背景 | 完全公开 |
| 标准初赋制剂 | 约30% | 治疗一次严重疾病，或使健康成年人停龄约一年；两种用途消耗等量 | 童年与青年期大多正常，过半在30—40岁进入白潮 | 两种用途均公开 |
| 外星警戒区 | 超过40% | 没有可靠的额外疗效 | 出生期开始出现循环、发育和神经小异常 | 专业资料可查 |
| 外星死亡线 | 超过50% | 没有可靠的额外疗效 | 急性崩溃与死亡概率陡升 | 专业资料可查 |

- 人类没有设计治疗量与停龄量两套药。外星资料给出的是同一条提取曲线；人类为远离40%警戒区和50%死亡线，把30%定为唯一标准量。
- 治病与停龄的区别不在剂量：治病通常在完成一次或少数疗程后结束，停龄则每年自动产生一份新的等量需求。
- 一名新生供体形成一份标准制剂。上一年度制剂降解后，下一年可以使用另一名供体的制剂，不存在终身认主，也不需要解释多供体拼接。
- 初赋可以长期低温保存；地球验证的可靠效价期为35—50年，之后逐年衰减。它可以形成几十年的库存与金融权力，但不是永不贬值的无限仓库。

## 三、人口与年度流量区间

### 1. 世界基数

- 三战后重建稳定期总人口：约1.4亿—1.8亿。
- 年出生人口：约65万—85万。
- 人口不是持续高速增长；战后创伤、城市化、长教育期与远航社会使生育率长期偏低。

### 2. 公开治疗需求

- T-40至T-31：辐射相关癌症与免疫病仍处高峰，年治疗成品需求约18万—30万份。
- T-30至T-18：疾病负担下降、适应症扩大，年需求约14万—22万份。
- T-17至T0：常规医学继续进步，年需求约10万—18万份。

治疗的短期用量始终大于早期停龄人数。公众看见的繁荣不是假景：绝大多数初赋医疗在眼前确实用于治病。可是疾病疗程会结束，停龄承诺不会自行结束。

### 3. 年度停龄人数

| 时间 | 活跃年度依赖者 | 制度状态 |
|---|---:|---|
| T-35 | 2千—5千 | 首批公开限定队列 |
| T-30 | 1万—2万 | 十年公开复审后扩大 |
| T-24 | 5万—8万 | 六方关键岗位与工程名单膨胀 |
| T-18 | 11万—16万 | 继任失效，年度义务固化 |
| T0 | 16万—22万 | 停止新增，但既有依赖与私仓仍在 |

这批人不足总人口的0.2%，却每年形成新的刚性义务。公开治疗会随病人康复结束，停龄则只要受体活着，下一年就自动再次到期。

### 4. 标准提取覆盖率

| 时间 | 全球新生儿标准30%提取比例 | 说明 |
|---|---:|---|
| T-40至T-36 | 由极小规模升至2%—8% | 治疗与停龄人体项目使用同一标准量 |
| T-35至T-31 | 8%—15% | 少数完整覆盖区；区内可达约80% |
| T-30至T-28 | 15%—30% | 公开扩容，储备目标第一次上调 |
| T-27至T-25 | 40%—60% | 六方分别建仓，重复储备开始 |
| T-24至T-18 | 70%—80% | 七年峰值；“八成一代”的严格含义 |
| T-17至T-12 | 55%—70% | 仓储渐满，弱异常出现，仍未证明因果 |
| T-11至T-8 | 30%—50% | 官方收缩，黑市与私仓占比上升 |
| T-7至T0 | 官方冻结至停止 | 隐蔽提取短暂延续，随后失去制度供给 |

“80%”不是整整二十多年全球恒定抽取，也不是80%世界人口；它指黄金扩张峰值年份出生的一代。按上述出生率与曲线，标准供体累计约800万—1000万，终身预期白潮患者约400万—600万。

## 四、为什么会抽得远多于当年实际用量

停龄依赖者即使到T0只有十几万至二十余万，也能推动数百万库存形成，原因不是单一消费，而是四次重复计算：

1. 六方各自按最坏断供情形建立10—15年战略仓，拒绝共享全部底数；
2. 阿卡迪亚按原定任务锁定长期医疗与关键人员储备；
3. 医院必须保留公开治疗安全库存，不能在账面上被停龄计划直接调用；
4. 私人仓、黑市和金融质押把“未来可以使用”本身变成资产。

六方依靠新生人口持续增长，才让这些互相冲突的承诺在每一年度都显示为“已覆盖”。这不是某个会计师算错，而是整个制度默认下一年度仍会有新的孩子提供增量。

T0前后，全球仍可物理确认的标准制剂库存约为400万—600万个当量，但它被分仓、冻结、质押、查封和带上阿卡迪亚，质量等级也不一致。**库存总量充足，不等于某个患者拥有调用权。**

## 五、试验与白潮时间账

- 十年人体计划累计供体约10万，所有供体都按30%标准量提取；疾病治疗与停龄两个受体组均公开观察。
- T-40启动极小规模人体项目，随后依照即时指标、儿童随访和真实疗效逐级扩容；T-35前后进入首批完整覆盖区。
- T-30总结时，最早标准供体已经随访十年，所有传统指标仍然正常。制度没有借用另一剂量的数据，也没有伪造结果；它只是把十年真实安全外推到三十五岁以后。
- T-7起出现的是T-35前后覆盖区中的早发哨兵；约T-5以后，最早大队列进入三十岁，临床聚集才开始形成。T-24以后出生的“八成一代”到T0尚未普遍进入三十至四十岁发病窗。
- 因此T0的危机由两部分组成：较小但已经足够证明因果的首批临床浪潮，以及数量大得多、知道自己未来可能发病却尚未发病的人。

长生海的**固定设计容量为2000万人**。这个数字不是“已经发病人数”，而是对整个校准时代不确定性的工程回应：

- T0前后确诊或重症临床患者约8万—20万；
- 已确认或能高度推定接受过标准提取、但尚未发病者约700万—850万；
- 出生记录缺失、类别授权含混、黑市或承包链无法反查，因而无法排除曾被提取的人约1000万—1200万；
- 三类按最终安置身份互斥统计，获准和选择进入低温者约1800万—2000万；拒绝入舱者、尚未排到舱位者与后续新增申请使容量长期接近饱和。

工程从危机前期便开始把战时地下掩体、轨道货运井、废弃数据中心和沿海能源站改造成低温区；真相承认后再由自动化工厂以标准黑色舱体滚动扩建。发射时可见设施的设计位已经达到2000万，实际启用接近饱和，而不是在几个月内凭空建成两千万座独立医院。

这使长生海真正成为一片改变人口结构的黑色大陆，又不要求两千万人已经同时病倒：绝大多数人是在没有检测手段、也不敢等到三十五岁以后才决定时，主动把自己从公共时间里移走。

## 六、白潮因果为什么只能由制度自己承认

早期怀疑者并非没有查：医生看见病例，家庭回忆设备与针孔，审计员发现实体产出大于公开治疗、停龄和申报储备之和，媒体追问为何“未提取者”也发病。问题在于他们拿到的都只是局部真相。

- 公共医疗与停龄总配额可以解释大部分出生分离量；
- 连续性用药账以隐私和战略安全拒绝公开个人交叉键；
- 实体冷链账只有容器，没有供体与受体身份；
- 黑市原本就没有完整身份记录；
- 白潮早期又能被分散诊断解释。

白雪曾短暂接近三账交叉处。她发现实体产出已经超过公开治疗、停龄配额与申报储备，却也看见每本账在各自审计范围内都能成立；若强行申请六方交叉，会同时冻结公开治疗、续生配额、阿卡迪亚储备与大量家庭随访。因果尚未成立时，她接受“重复储备与工艺损耗足以解释缺口”的结论，选择继续留在制度内审计，并在后来成为年度受益者。这是她独立于“驳回弱关联申请”的另一重原罪。

真正的公开发生在以下事实同时出现以后：

1. 标准提取供体的发病率越过统计红线；
2. 白潮患者总数超过官方提取名册能够容纳的人数，“未提取者发病”被证明包含删键、谎报与黑市；
3. 实体库存量远超公开治疗、公开停龄与申报灾难储备所需；
4. 多方各自掌握的数据已经可以在制度之外互相校验；
5. 继续否认会使全部医疗记录失去公信力，并诱发产科拒绝与冷链失控。

于是六方不是被一名英雄“曝光”，而是在再也无法维持医疗秩序时联合承认：合法的30%标准提取本身会在一代人后造成白潮，超额库存和非法流量又把受害范围推得比官方名册更大。它们停止新增提取并开放部分交叉账。白雪参加文本起草和签署，迫使公告写入标准制度责任、自己的年度用药与当年降级决定；她改变了承认的完整程度，却不能把自己写成发现一切、拯救一切的泄密者。

承认之后，官方叙事迅速把“合法制度造成的一代伤害”改写成“雷蒙利用制度漏洞实施的系统性犯罪”。这句话并非全假：雷蒙确实有罪；它真正遮住的是，没有他的那些年份，合法提取同样每天发生。

## 七、正文数字纪律

- 正文可写“数十万”“近千万”“两千万设计位”“不足千分之二”，避免每章报表；“长生海两千万”是允许反复出现的固定意象数字。
- “八成”只用于峰值出生代或特定覆盖区，不用于全部历史人口。
- 治病与年度停龄两种用途从人体试验起就公开；后期不得再把“发现续生存在”写成悬疑。
- 两次数量失配必须分开：先是实体产出大于公开治疗、停龄与申报储备之和，后是白潮患者多于官方提取名册；前者指向超额囤积，后者指向删键、谎报和黑市。
- 任何人说“药明明够”时，都要回答的是调用权、质量、仓属与下一年度义务，而不是只回答物理总量。
- “雷蒙平账”只能指危机后以处罚一个明面恶人结清集体责任，不能再写成他负责设计三本账或维持全系统运行。
