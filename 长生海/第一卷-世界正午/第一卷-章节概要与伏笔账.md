# 第一卷《世界正午》章节概要与伏笔账

> 本文件用于后续续写和校稿，不属于小说正文。正文为序章及第1—17章。

## 卷内任务

第一卷不负责解释白潮，而负责证明三件事：这个时代真的繁荣；初赋技术真的救过人；许渡原本真的拥有可以继续下去的人生。卷末只让身体先发出信号，不给病名、死期和完整因果。

白雪是叙事主角。她的卷内决定链为：崇拜父亲创造奇迹 → 选择审计而非继承父亲实验室 → 在普通工作中学会记录不等于现场 → 面对弱关联时放弃九十天升级复核 → 得到独立船位并发现私人治疗空白。许渡承担时代生活的完整度，但不接管全书方向。

## 第一卷结束时，读者应当知道

1. 三百年前发现的遗星医疗结构真实存在，人类由此复原了能够救人的稳态重建。
2. 伊莲娜真实获救；这项技术不是骗局。
3. 新生供体流程合法、补偿真实、短期检查正常，且许多家庭确实因此改善生活。
4. 五年安全被当作扩大依据；韩真等人反对过，白远山、伊莲娜与雷蒙德各自以不同理由推动连续使用。
5. 某些供体一代出现过恢复、睡眠和免疫的小偏差，但仍不足以在当时证明共同因果。
6. 白雪曾放弃九十天升级复核，并发现自己有六次受限低剂量记录。
7. 许渡二十八岁时旧伤重裂，身体出现第一次不能再被当成单纯优势的信号。

## 第一卷结束时，不能让读者确定

1. “复稳质/续生质”究竟来自新生儿身体的什么机制。
2. 许渡出生提取的精确剂量、病名、死期，以及他是否一定会死。
3. 白雪是否真的接受过续生、由谁决定、白远山留下了什么资料。
4. 七例弱关联是否属于同一种病，记录缺失是普通失真还是人为处理。
5. C-9是什么、遗星医疗舱为什么只保留五年版本、那里是否仍有文明。

## 第二卷直接接续点

- 时间不跳远，从许渡二十八岁旧伤重裂后的检查开始。
- 许渡首先担心停工、收入与房子，不能立刻把自己变成文明受害者代表。
- 白雪先动用专家通道，再逐步认出李承济申请中的病例；她的第15章选择必须持续发作。
- 第19章之前不由旁白先替陈澜定罪；出生授权交出来以后，家庭对同一笔补偿的解释才真正破裂。
- 白潮名称、剂量梯度和一至三年死期继续按目录延迟，不因卷末钩子提前一次讲完。
