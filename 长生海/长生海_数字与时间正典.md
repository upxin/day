# 《长生海》数字与时间正典

> **使用规则：** 本文件是全系列人口、采集、剂量、病程、库存、冷冻与航程数字的唯一总账。故事大纲和章节只写叙事所需的模糊量级；若其他文件与本表冲突，以本表为准。修改任何核心数字时，必须先修改本文件，再检查受影响章节。

## 一、T-0世界人口

| 项目 | 正典值 | 作用与边界 |
|---|---:|---|
| 全球总人口 | 约7亿 | 技术高度发达但长期少子化，人口缓慢下降，并非末日开局。 |
| 核心医疗网络覆盖人口 | 约2.5亿 | 高度城市化，依赖统一身份、妇幼、冷链、能源与AI调度系统。 |
| 边缘人口 | 约4.5亿 | 接入程度不一，直接采集较少，但会被核心供应链崩溃波及。 |
| 全球年新生儿 | 约720万 | 粗出生率约10.3‰；以80—100岁自然寿命计算，足以支撑缓慢人口下降。 |
| 每年进入核心妇幼网络的新生儿 | 约500万 | 约占全球出生的69%；包括从边缘地区转诊到核心医院的孕妇。 |
| 首次生育年龄 | 九成以上在27岁以后 | 晚育让生殖损伤在白潮爆发前长期被误认成社会趋势。 |
| 普通人自然预期寿命 | 80—100岁 | 盛世医学已经能处理绝大多数疾病，但不能阻止全身衰老，更无法避免事故死亡。 |

### 为什么7亿人口不浮夸

7亿人口不是灾后残值，而是长期低生育、晚育和高自动化共同形成的稳定下降阶段。AI承担大量生产与维护，文明不需要数十亿劳动力；但自然出生仍是初龄质唯一来源，所以数百万新生儿在制度眼中反而比旧时代更“稀缺”。

### AI承担工作与“人类独立能力保护期”

- **AI承担绝大多数可重复劳动。** 制造、运输、基础诊疗、设施维护和常规模型计算主要由AI与自动设备完成；程野等人受训，不是因为人类在这些工作上比AI更快。
- **全球教育体系把三十岁以前定义为“独立能力保护期”。** 这一阶段并不禁用AI：医疗、安全、检索、翻译和模拟工具照常开放；被限制的是让代理智能替本人完成判断、答辩、关键操作和资格考核。任何申请深空、公共决策、应急医疗和基础设施岗位的人，都必须先证明自己能在断网、模型失配与AI故障时独立工作。
- **三十岁不是生物学魔法线，而是制度线。** 长寿、晚育社会把人成期延长到三十岁；早期自动化曾出现过整代人只会调用系统、不能在系统失效后接管的事故，因此各地以三十岁作为完成基础认知、手工和公共责任训练的统一期限。三十岁以后可以合法使用更高等级的代理AI，但关键职业仍保留定期无AI复核。
- **好学校仍然稀缺。** AI可以把同一套知识免费教给所有人，却不能同时提供真实生态舱、轨道实训、故障设备、长期人类导师和被深空计划承认的责任资格。阶层购买的不是“答案”，而是进入真实问题、被机构看见和取得认证的机会。
- **深空船必须保留人类能力。** 航行中通信以年计，C-9又存在模型外生态；AI可以操纵船，却不能成为文明唯一的知识载体、价值裁判与下一代教师。人类学徒的正式功能接近“文明接管员”：平时让机器做得更好，机器无法决定时承担决定。

### 采集区域的唯一口径

- **核心网络不等于核心居民。** 每年约500万名新生儿进入统一妇幼网络，其中约一半至六成长期生活在核心连接区，其余是从边缘区域转诊、集中生产后再返回家乡的家庭。
- **公开标准期的常规采集区，就是这条统一妇幼网络。** 每年约500万例“免费适应性校准”与约500万份年产出一一对应，不再另造一个看不见的供体人口。
- **网络之外每年约220万名新生儿不进入常规采集。** 家庭分娩、地方产房和离线聚落缺少统一冷链、身份和洗白流程，强行扩张收益低、暴露风险高。
- **黑市寄生在出生窗口，不另建一套供体社会。** 它主要通过合作产房、私人妇幼机构和少量流动接生点，以“新生代谢研究补助”向家庭付费；家长可能知道参加过有偿项目，却不知道成人续生用途和远期代价，也可能连采集发生过都不知道。黑市只认货，不建立可反查到孩子的供体名册。

## 二、采集时代的四个阶段

> **统一口径：** 一名新生儿只能在出生后的十小时窗口内完成一次采集；不存在多年后补抽，也不使用“重复采集”制造病程。一名被采集者、一份标准产出和一次成人年度剂量是三个相关但不能混写的统计单位。

| 阶段 | 时间 | 年龄（T-0） | 人数口径 | 剂量特点 | 剧情功能 |
|---|---|---:|---:|---|---|
| 秘密验证期 | T-44至T-40 | 40—44岁 | 总计不足1万 | 低剂量、现取现用，方法尚未稳定 | 纳赛尔、第0批人体受体及早期供体；不承担全球危机规模。 |
| 资本验证期 | T-40至T-38 | 38—40岁 | 有记录约10万；同期已出现极少量账外交易 | 从低剂量逐步接近半循环；正规设备最精确 | 足够证明成人续生有效，却不足以等待三十五年供体安全结果。 |
| 秘密产业期 | T-38至T-10 | 10—38岁 | 有记录约2990万；黑市人数未知，作者模型按约600万估算 | 正规链逐步固定为半循环；黑市均为一次采集，但部分设备会一次过量 | 构成首轮白潮、十五年疯狂扩张和“未采集者也发病”的假阴性。 |
| 公开标准期 | T-10至T-0 | 0—10岁 | 有记录约5000万 | 统一为半循环、截留约50%初龄储备 | 十年随访看似漂亮，真正白潮仍在未来。 |

### 秘密产业期的作者内部时间模型

> 下表用于作者验算规模，不能在书中写成后来者已经掌握的完整统计。黑市没有个人名册，分段人数只能是根据库存、出生量和病例反推的中值。

| 子阶段 | 时间 | 作者模型中值 | 叙事含义 |
|---|---|---:|---|
| 产业爬坡 | T-38至T-35 | 约400万 | 三十年保存突破后供应链迅速扩张；这一批在T-0正好35—38岁。 |
| 无反馈疯狂期 | T-35至T-20 | 约2300万 | 连续十五年没有可信长期负面反馈，初龄质从药变成寿命资产。 |
| 假阴性延续期 | T-20至T-10 | 约890万 | 约二十岁哨兵已出现，但患者档案显示“从未采集”，扩张没有停止。 |

资本验证约10万 + 秘密产业作者中值约3590万，合计约3600万。这个数字是**作者的模型中值**，不是人物能够查到的精确名单。

### 早期高风险代的唯一口径

- **时间：T-40至T-10。**
- **有记录人数：约3000万。**
- **黑市人数：无法核实，作者估算约400万—800万，中值约600万。**
- **实际总量：估计约3400万—3800万；作者验算中值约3600万。**
- **T-0年龄：10—40岁。**
- “九成”是模型给出的发病概率上限，不是一个拥有完整分母的精确死亡名单。仅有记录的约3000万人，按九成计算就已经是约2700万人；黑市之外还有多少人，任何角色都无法给出终值。
- T-38至T-35出生、现年35—38岁的约400万人构成T-0首轮集中白潮。二十岁上下只有极少数黑市一次过量采集者或先天储备偏低者提前成为哨兵。
- T-40至T-38的正规资本验证样本人数少、剂量更谨慎，多数在二十岁时仍然健康；这恰好加强了上层对早发病例的错误判断。T-35之后的年轻者会在未来二十多年继续进入风险窗口。

### 黑市与“无法自证”的唯一口径

- **黑市只记录货，不记录孩子。** 货物最多保留日期、活性和等级，不存在供体姓名、出生编号与受体的统一映射；付款被包装成研究补助、现金或匿名转账，也没有可还原全体受害者的中央账本。
- **一名婴儿仍然只采集一次。** 黑市危险来自一次操作中的剂量失控、设备误差和更激进的截留比例，不来自重复采集。
- **官方所谓“未采集者发病”是被污染的对照组。** 约二十岁的最早病例中，一部分实际上在出生当晚被黑市采集，但中央档案显示从未进入采集流程；同龄正规低剂量样本大多健康，于是上层一度据此否定采集致病。
- **真相公开后仍无法补出完整名单。** 二十多年后的针孔早已消失，常规新生儿本来就可能接受采血与输液；有的父母记得收钱或签字，有的只记得孩子被抱走检查，有的当时昏迷、已经去世或出于愧疚否认。口述可以构成历史，却不能在T0立刻替每个人提供医学证明。
- **T0没有可靠的回溯检测。** 初龄质原物质无论是否被抽，十小时窗口结束后都不再以原始形态存在；真相刚公开时，采集时代出生、尚未越过危险年龄的人只能面对概率。T0真相公开数日后，多家公共研究机构启动“初生定标回溯计划”，方向是寻找被拿走以后留在成年造血与免疫谱系中的长期断层，而不是寻找已经消失的原物质。T+2以后，已知供体队列、设备日志与数百万纵向样本才使研究者确认“初生定标断层”；T+3第一代检测只能给出“支持采集、支持未采集、无法判定”三类结果，不能恢复完整黑市名单，也不能修复损伤。

### 公开标准代的唯一口径

- **时间：T-10至T-0。**
- **总人数：约5000万。**
- **T-0年龄：0—10岁。**
- 他们不是已经被证明安全，只是尚未走到主要发病年龄。

### T-0公开随访数据（宣传口径）

| 指标 | 对外数据 | 真正含义 |
|---|---:|---|
| 十年内表面健康 | 99%以上 | 公开标准代尚在童年，只证明当下没有可见损伤。 |
| 家长报告轻微异常 | 约0.05%—0.1% | 反复低烧、疲倦、伤口难愈等，仍落在普通儿童背景噪声内。 |
| 童年重度崩溃 | 低于十万分之一 | 主要来自极端设备事故、单次严重过量和先天低储备，不构成普通半循环病程。 |
| 生命底图建模成功率 | 99.7%以上 | 校准确实能建立终身用药、过敏与代谢模型，这项公开福利并非全无作用。 |
| 新生期意外处置改善 | 约18% | 来自监测和AI干预本身，不是初龄质被提取后的好处。 |

### 从少量试验到大规模采集的唯一契机

- 盛世医学在初龄质出现前就能处理绝大多数疾病；初龄质首先突破的是**全身衰老**，不能把它写成治愈普通疾病后才得到支持。
- 最初的活性只能短时保存，人体试验以低剂量、现取现用为主，没有理由也没有能力大规模采集。
- T-38前后，避光低温保存从小时级跃升到约三十年。这个突破才是第一次大规模采集的开关：初龄质从当日用掉的试验材料变成可以入库、质押和滚动换仓的寿命资产。
- 同期，“新生生命底图”获得试点许可并进入部分核心妇幼机构；T-10才由分散试点升级为核心网络的免费公共服务。它确实能建立终身用药、过敏和代谢模型；隐藏的旁路分离模块只是搭载在真实有用的检查上。
- 家长不知道成人续生原料来自孩子，只看见无失血、无可见创口、能领取终身健康档案的免费校准，因此主动参加并不降智。
- 前期研究没有出现指向白潮的明确阳性证据：短寿命动物完成生命周期，早期低剂量人群也长期正常。错误发生在把低剂量与错误模型的安全结论外推到半循环标准；**真正的明知风险从成年病例形成剂量相关性以后才开始。**

### 法律许可的唯一口径

- **T-50动物阶段：** 闭门会议批准机密动物同源验证，项目合法但不公开。
- **T-44至T-40人体阶段：** 纳赛尔签发一次性绝密医疗例外，只覆盖少量低剂量新生供体研究和自愿成年受体，不自动授权产业化。
- **T-38生命底图试点：** 《新生生命底图与匿名校准样本管理规范》允许闭合循环检测、血液全部回输、保留去身份化分子校准样本，并允许用于未来医学研究和许可转化。家长有拒绝权；参加者换取真实有效的终身健康模型。
- **T-10公共标准期：** 试点升级为免费公共医疗服务，同一套许可覆盖核心妇幼网络。普通医护只知道检测和匿名留样，不知道样本等于成人续生年剂量。
- **不得写成“检测废料自动归医院”。** 它是家长签字捐出的匿名校准样本；被隐瞒的是不可复制的价值、实际成人用途、无法扩增的事实与长期供体风险。
- **稳态重建疗法有成人药物批文。** 对外称有效成分由C-9机制、生命底图库与实验室扩增工艺产生；真实情况是扩增失败，每份药都消耗一份新生样本。
- 当剂量与成年发病的关联已经可信，继续沿用旧同意书、隐瞒风险和扩大采集，不再属于早期的不确定判断，而构成许可欺诈与系统性伤害。

## 三、一次采集与一份剂量

| 项目 | 正典 |
|---|---|
| 可采集窗口 | 从胎盘循环终止起约10小时；最高活性集中在最初2小时。十小时后新生儿完成第一次代谢转换，未分离的初龄质永久失去提取价值。 |
| 有效供体边界 | 只有经历自然母胎过程的人类新生儿能为人提供完整效应；动物与C-9样本只能用于机制研究，跨物种注射无效且致命。 |
| 为什么不用脐带血/胎盘 | 产后残余物只含分散前体和局部信号；完整协议在新生儿第一次独立循环中才组装，多份残余物不能靠混合累积成一份年剂量。 |
| 标准操作 | 按新生儿心排量计算一个全身循环周期，将约一半循环血流短暂旁路、分离后全部回输。 |
| 单次铁律 | 每名新生儿只进行一次旁路分离；正规与黑市都不允许用“重复采集”解释后果，黑市早发来自一次过量。 |
| 实际失血 | 接近零；截留的是循环中的初龄活性复合系统，不是抽走半身血液。 |
| 新生儿保留量 | 约50%初龄储备，随后写入骨髓、神经、免疫和生殖系统。 |
| 标准产出 | 一名新生儿的一次标准采集，约等于一份“成人全身年度剂量”。 |
| 成人效果 | 一份可使一名成年人保持约一年青壮期精力、组织修复与代谢水平；连续使用可逐步回到个人30—40岁生理峰值，但不会变成儿童。 |
| 停药结果 | 普通成年使用者重新衰老；长期依赖者会出现更快的代偿追债。 |
| 定向治疗 | 一份也可用于一次重大器官或组织修复；结构修复可以长期保留，但不等于此后终身年轻。 |
| 储存期限 | 约30年；接近期限后活性快速衰减，不能无限囤积。 |
| 成年后能否回查 | **T0不能直接回查。** 原物质和针孔都不存在；T+3以后可通过“初生定标断层”检测部分重建采集概率，但仍有无法判定区，且只能识别发育后果，不能指出采集机构、库存去向或受益者。 |

### 必须保留的区别

- **一次性修复**和**全身每年续生**是两种使用方式。地球开篇出现的普通公益受益者只得到一年的全身年轻状态，随后会重新衰老；真正的半永生必须每年持续获得完整年度剂量。
- 初龄质不能防止失压、外伤、暴力、能源中断等物理死亡。

## 四、受益者与库存总账

| 项目 | 正典量级 | 说明 |
|---|---:|---|
| 全球稳定年度续生者 | 约1200—2000人 | 主要是跨国决策者、资本掌控者和极少数核心科学家；不是百万级，也不是全民医疗。 |
| 每年一次性治疗/公益展示者 | 约200—500人 | 用于维持“原则上人人可治”的公共神话；绝大多数普通人仍负担不起。 |
| 每年真实医疗消耗 | 少于3000份 | 与约500万份年采集量相比几乎可以忽略。 |
| T-0有记录的被采集者 | 约8000万人 | 早期有记录约3000万 + 公开标准代约5000万；这是后来者能用档案确认的下限。 |

### 没有上船的续生者

阿卡迪亚号只带走稳定续生者中最核心的一层，其余人不会自动转化成良知派。但他们大多是高价购买者、地区中介或单一节点管理者，并不掌握全球证据销毁、跨区密钥与深空撤离系统。主导层离开后，他们的理性选择反而分裂：有人继续藏药和销毁记录，有人用账本换取宽免，有人为报复上船者而公开竞争对手的仓库。正是这种互相背叛，而不是集体忏悔，让真相和大部分库存在短时间内失去了统一保护。

### 为什么采集500万、真正使用却不到3000

这不是医疗供需，而是被人为制造的寿命资产：

1. 每一密封匣入库就被记作“一年可转让健康寿命”；
2. 跨国集团和决策网络用它作抵押、储备、权力凭证和未来配给权；持有的不只是某一支药，更是对未来持续采集链的优先索取权；
3. 真实供应量、仓库规模和失效率全部保密，垄断集团用“未来会逐步扩大至全球富裕人口”的市场预期维持天价，却不必现在就让药进入公开市场；
4. 采集端按入库量获得预算与收益，没人需要等到药被注射才赚钱；
5. 三十年保质期并不阻止资产化，因为地球系统通过先进先出、临期减值和新生批次持续补仓运转；账面上被宣传为“永久库存”的，其实是一条不能停的滚动供应链；
6. 真相公开后，新增采集停止，库存合法性、抵押价值和滚动换仓同时崩溃，寿命资产泡沫与医疗体系一起爆炸。

在地球上，“永生”从来不在某一座仓库里，而在每年都有新生儿进入系统这件事里。阿卡迪亚号一旦离开地球，带走的物理库存就不再能滚动换仓，所谓“永生资产”立刻退化为一批只剩三十年寿命的药。这正是他们必须同时带走播种者与提取设备的数学原因。

所以核心罪恶不是“为了救两千人不得不牺牲几千名孩子”，而是：**为了制造和囤积可定价的未来，先后抽取了八千多万名孩子。**

### 真相公开后，库存去了哪里

库存不能凭空消失，也不能被写成永久解药。它承担一段明确的“过桥期”：

1. 真相公开后，各地在数月内陆续追缴约5000万—6000万份仍有效库存；
2. 这些剂量优先用于已经发病及模型判定高风险者，能暂时覆盖白潮，却不能重建他们自己的出生定标；
3. 若覆盖约2700万—3400万名已发病或高风险者，账面平均约能争取一年半至两年；物流损耗、个体差异、分配延迟和个人拒绝会把许多人的实际获益压到一年左右；
4. 这段时间正好支撑T-0至T+4的冷冻工程滚动建设：先用库存延缓，舱位建成后再分批进入；
5. 新采集已经停止，库存耗尽后无以为继，因此长生海不是“有药不用”，而是文明明知药只能再拖一小段时间。

这还产生一个重要伦理冲突：受害者为了多活一年，必须决定是否使用另一名孩子被偷走的初龄质。有人接受，有人拒绝；不存在统一的道德答案。

### 阿卡迪亚号“温和采集”的内部算盘

- 总人口约5万，其中续生核心150—300人。
- 前30年依靠约1万—1.5万份库存，不立即抽取船上新生儿。

- 权贵把这个比例称为“温和、可持续”，但被抽中的孩子仍承担完整代价；所谓温和只是把暴力稀释进统计学。

### T-0危机规模

- 早期高风险代有记录约3000万，计入黑市后估计约3400万—3800万，作者模型中值约3600万。

- T-0已经出现明显症状或进入快速衰败期的约300万—400万人，主体是T-38至T-35出生、现年35—38岁的约400万产业爬坡样本；二十多岁患者仍只是散落其间的早发哨兵。

- 公开标准代约5000万人尚未到发病年龄，已经被确认存在长期风险，但其中多少人会出现轻度代价、多少会在40岁前进入重度白潮，T-0时仍无法给出可信终值。

### 婚育闭环

- 九成以上人口把首次生育推迟到27岁以后。
- 大部分普通剂量受害者在35—38岁集中发病前已经结婚并完成第一次生育；初龄采集因此不会提前截断供体链，也不会让这一代集体绝育。
- 三十岁前后的轻微难孕、流产和精卵质量下降被归因于晚育、压力和环境，反而延误因果确认。
- 周艾35—36岁，是T-38至T-35产业爬坡期的普通受害者。她刚按这个时代的常见节奏生下第一个孩子，并主动让孩子完成“新生校准”；数月后自己进入白潮，形成不是巧合而是统计必然的双代悲剧。

### 真相公开后的恐惧与人口反馈

- 真相公开只能证明采集会导致白潮，不能立即证明某一个人出生时究竟有没有被黑市采集。已确诊者至少得到答案，尚未越过35岁的整代人只能在检测成熟前等待。

- 供应收缩推动库存价格与黑市报价上涨，进一步加剧对剩余产房的渗透和社会恐慌。所谓人口崩盘首先是出生体系、青年劳动力和核心网络的崩盘，不是7亿人在几年内同时死亡。

## 六、长生海冷冻工程

| 项目 | 正典 |
|---|---|
| 建设期 | T-0真相公开后至T+4，滚动建设，不是几个月突然完成。 |
| 进入人数 | 约2800万人。 |
| 主要来源 | 早期有记录者、被模型判定高风险者，以及因黑市无记录而无法证明自己安全的人。 |
| 未进入者 | 早期风险池估计约3400万—3800万；未进入者包括死亡、拒绝、轻症、失联、来不及进入及选择清醒生活的人，不能再写成精确“剩余800万”。 |

### 冷冻不是暂停键

- 长生海采用的是极低代谢维持，不是把时间降到绝对零。舱内仍保留最低限度的膜电位、组织灌注校验与神经连接维护；人的外表几乎不衰老，生物过程却没有真正停止。
- 真正被逐年消耗的是**可逆概率**：细胞膜损伤、微血栓、蛋白聚集、神经连接漂移、宇宙辐射与设备校准误差会缓慢累积。界面必须显示“预计可逆率区间”，不能显示一个虚假的“剩余寿命”。
- 八十年只是工程设计维持期，不等于八十年后可以整齐唤醒。越早入舱，身体越完整，却要承受更长的低温损耗；越晚入舱，低温时间缩短，白潮造成的不可逆损伤又更重。冷冻始终是一项两边都在失去的选择。
- T+4约有近2800万人处于冷冻维护网中，其中既有确诊患者和高风险有记录者，也有无法自证、选择在检测成熟前保存身体的无症状者。第一代回溯检测获得有限许可后，少量明确阴性者被分批唤醒并腾出舱位；阳性者继续沉睡，无法判定者仍要选择。林微在T+2按普通风险顺位进入，不因工程师身份获得提前舱位；T+3被纳入随机验证队列，确认未采集后唤醒。

### 2800万为什么能在四年建成

- AI施工群将既有数据中心、地下工程、医院冷链和战略避难设施改造为区域舱群；
- 前两年由追缴库存为大批患者争取时间，冷冻舱不是等所有人同时完成后才启用，而是建成一批、进入一批；
- 较年轻、尚未进入主要发病窗口的受害者在医学上本可以再等，但他们不能确定数年后还有没有稳定能源、产业链、监护人和可供入舱的设施。因此一部分人是在身体仍健康时主动提前入舱：他们浪费了本可清醒度过的年月，换取“在冷冻系统还存在时暂停”的确定性。这是2800万规模能在四年内形成的关键，也是一道真正残酷的自愿选择；
- 平均每年部署约700万舱，单舱连同区域设备若按数百公斤至一吨计，材料规模仍低于旧时代全球汽车工业的年产量；
- 真正瓶颈不是造壳，而是长期能源、制冷剂、密封件、传感器和维护机器人；这也解释了为什么它们最终会分区熄灭。

### 他们最怕的究竟是什么

不是一个抽象的“世界会评价我”，而是一组非常具体的后果：库存被夺、续生被禁、身份与资产失效，然后在自己逐日衰老的身体里等待审理。对已经续生数十年的人而言，**停药就是他们最能理解的死刑**。这也是他们宁愿放弃地球的底层恐惧。

## 十、总量自检

### 1. 出生量是否容纳采集量

- T-40至T-0共40年，累计出生约：720万 × 40 = 2.88亿人。
- 同期有记录采集约8000万人，占同期出生约27.8%；计入无法核实的黑市后，实际估计约8400万—8800万人，占约29.2%—30.6%。
- 公开期每年采集500万，占年出生约69.4%，与核心妇幼网络覆盖率一致。

### 2. 早期高风险代与十五年疯狂期是否成立

- 有记录的资本验证约10万，有记录的秘密产业样本约2990万，合计约3000万。
- 黑市没有个人数据，只能估算约400万—800万人；因此早期实际总量约3400万—3800万，作者中值约3600万。
- 作者中值的阶段拆分为：产业爬坡约400万 + 十五年疯狂期约2300万 + 假阴性延续期约890万，再加资本验证约10万，合计约3600万。
- 第一个约二十岁哨兵在T-20出现以前，作者模型中已经采集约：10万 + 400万 + 2300万 = 2710万人。T-40至T-20同期出生约1.44亿，被采集者中值约占18.8%，足以形成文明级既成事实，又没有超过出生量。
- T-38至T-35约400万人在T-0正好35—38岁；按80%—90%明显白潮率，对应约320万—360万人，能够支撑首轮300万—400万危机规模。

### 3. 2800万冷冻者是否有来源

- 早期高风险池估计约3400万—3800万，另有一部分因档案不可信而主动提前冷冻的未知风险者。
- 进入长生海约2800万，约占早期风险池的74%—82%；由已发病者、模型高风险者和无法自证者共同构成。
- 未进入者由死亡、拒绝、轻症、失联、来不及进入与选择清醒生活共同解释，不再给出一个虚假的精确余数。

### 4. 6000万—7000万有效库存是否成立

- T-0时三十年保质期仍覆盖T-30以后的产出。按作者中值估算：疯狂期后十年约1530万 + 假阴性延续期约890万 + 公开期约5000万，理论毛量约7420万份。
- 扣除医疗使用、试验、质检失败、运输损耗、黑市即时消费、私藏和冷链报废后，仍有效库存约6000万—7000万份成立。

### 5. 为什么能造成全球危机

- 早期风险代估计约占全球人口4.9%—5.4%。不能把全部被采集者直接除以核心常住人口，因为核心妇幼网络也承接边缘地区转诊；按约一半至六成样本长期生活在核心连接区估算，早期高风险者约占核心人口7%—9%，公开标准代再占约10%—12%。
- 两代合计实际约8400万—8800万人，集中在学校、医院、科研、维护、运输和未来生育年龄，打击的是文明最依赖的青年层，而不是随机人口。
- 核心网络崩溃后，边缘4.5亿人会通过药品、能源、通信、零件和AI维护断供被间接卷入。
