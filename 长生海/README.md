## V10关键设定摘要

- 三战发生在已经拥有月球工业、轨道城市与初步恒星际工程的未来时代；以阿卡迪亚离港为T0，遗迹争夺和白硕救韩真发生在约T-70，不再沿用V9的2041—2048公历。
- 地下遗迹是一艘严重解体的C-9载人殖民船，外星乘员已经全部死亡。人类能看见尸骸、黑色医疗舱和C-9方向，却无法从残存资料判断死者属于成年续生派。C-9档案后来只能确认主舰在太阳系减速阶段发生结构—姿态系统级灾难，战争旧伤、材料疲劳和制动失败都进入事故链，但无法恢复唯一先后次序；死亡是物理事故，不是宇宙惩罚。
- 遗迹解译与战后重建持续二十余年；稳定初赋工艺在T-47至T-41间完成动物验证。人类只采用一种30%标准制剂：它既能协助一次癌症、免疫与多器官治疗，也能让健康成年受体维持约一年稳态，两种用途消耗等量。C-9把超过40%标为即时异常区、超过50%标为急性崩溃与死亡线，人类据此把30%定为唯一标准量，真实保留至少十个百分点。T-40同时启动公开疾病组与停龄组；T-30总结时，最早约十万名标准供体已经随访十年，传统指标仍然正常。
- 白雪不是幼年首例受体。她成年后在常规治疗、阿卡迪亚资格与合法复稳之间主动选择用药，因此仍是制度受益者，也必须承担自己的判断。
- 许渡、周野、罗凯、林微与白雪全部通过正常考试、区域选拔和专业评估进入阿卡迪亚国际联合大学，再被教务系统随机分入同一跨专业工程组。该组属于一个三十六人的合舱学群。出生补偿改善了许渡的住房与受教育条件，却没有供体专门录取通道；前四人所在的首批覆盖区形成约80%标准提取、20%明确未提取的同龄结构，后来黄金扩张只是把这个比例推向更大范围。白雪出生时未被提取，成年后才成为年度制剂受益者。
- 阿九、衡一是有名字的普通伴学／勘察设备，只保留少量幽默与高危作业功能；不承担记忆主题、调查功能、伦理选择或独立人物弧线。
- 许渡死亡，周野与林微结婚后进入长生海；唐静继续活着公开承担签字责任，并因反对罗凯再向新生儿索取而与儿子决裂；罗凯夺回船位、依赖库存远航，林微带着周野的记录登船。
- 记录制度只在地球篇高潮出现。长生海以连续数章完成，不在开篇提前展示规模和人物去向。
- “十年安全”是V10的人类认识论脊椎：30%标准供体随访十年，全部传统数据真实正常；制度却把十年内安全外推成三十五岁以后也安全。九十天复核、年度续针、低温等待与自续下限都要以不同形式重演“短期证据被改写成长期确定”的机制。
- 公众知道30%标准提取、治病与年度停龄，也知道一剂对应一名供体。后期秘密只剩个人流向、真实储备、黑市与删改记录；白雪青年时期发现实体产出大于公开治疗、停龄和申报储备之和，却在因果未成立时接受降级，后来主动成为受益者。
- 公共医疗、连续性用药与实体冷链三本账是六方制度原有的权限隔离，不由雷蒙设计。雷蒙在白潮因果逐渐成立以后仍拆散反向键、囤积、经营黑市并牟利；六方随后以真实刑罚将他塑造成唯一制度污染源，用处罚一个明面恶人完成讽刺性的“平账”。
- 黄金扩张的“八成”只指T-24至T-18峰值出生代，不是二十多年全球恒定抽取。T0先由较小的首批队列证明白潮，约800万—1000万名30%供体与更大规模的剂量不明者把长生海推到固定2000万设计位；发射时实际启用约1800万—2000万，绝大多数人尚未发病。
- 真相不是被一名英雄突然泄露：病例曲线、患者人数超过官方供体名册、实体库存又超过公开治疗、停龄与申报储备以后，六方为了维持医疗公信力被迫联合承认白潮因果。白雪能迫使承认文本写全责任，不能把自己写成单人拯救者。
- 白雪在船上以保护许渡尊严为由封存其临终求药记录，后被林微发现并公开解封。她因此不再只是犯过一次程序错误，而是会因爱再次控制别人语境的人。
- 阿卡迪亚本来是和平时代的恒星际探险、定居验证与文明备份工程，白潮使它同时成为求解船、病例船和部分高层的逃亡工具。正文在离港后直接越过约十个船年，以人物年龄、死亡空位和改变的关系表现航程代价。
- C-9历史只用少数关键章节呈现：当地文明也把五年真实安全扩大为成年续生制度，随后在出生中心、库存港和远航坞爆发屠杀与战争。成年续生派败退时带着库存、提取设备、繁殖人口名单和殖民方案驶向地球；新生自续核心依赖母城大型出生阵列，掌握在保护新生者手中，逃亡派还主动破坏相关接口，以免殖民地孩子失去供体功能。正文不追写航行，只在C-9档案与地球残骸编号吻合时揭露身份。
- C-9新生自续只在出生十小时内、完整初赋尚未嵌入时成立；接受者正常长大，成熟后保持生理稳态。提取与自续不可兼得，同一个孩子只能保留自己的未来，或成为成年人一年的药。
- 初赋可以按比例分离，但人类正规系统只采用30%标准量，不同供体不能在同一次疗程中拼接。成人复稳实行“单次疗程一源”，上一剂一年内降解后，下一年度可以更换新的单一供体，不存在终身认主冲突。新生自续要求未经制剂化分离的连续原生拓扑；完成标准分离便会关闭自续入口并埋下白潮风险。
- 初赋按可分离总量计量：常规校准净损失低于1%，约30%的标准供体中有过半会在三十至四十岁进入白潮。许渡记录完整；周野执行回写缺失，只能高度推定；罗凯家一直以为设备没有真正执行，最终由容器与受体账证明属于标准供体。同一剂量仍会因遗传、感染、创伤、生活压力与后续用药形成不同病程。
- 成年人的发育母版已经锁定，不能靠基因改写、器官置换或外源初赋重新进入自续。无人城因此没有许渡、周野、罗凯和长生海患者的解药；新生技术只能阻止后来者再次成为药，不能撤销已经发生的伤害。
- 雷蒙被留在地球公开受审，不登上阿卡迪亚。白硕、伊莲、杜衡等人留在C-9恢复能源、保存历史并等待人类新生自续的长期证据；白雪、林微、罗凯等人返航，把真相而不是解药带回地球。返航船始终收不到可靠的地球回应，正文也不切回地球替人物揭晓答案。
- 安禾确认怀孕后，库存模型提前数月确认罗凯下一次不可跳过剂量会落在预产期附近。父母与儿童利益代理拒绝提取，返航船连续性委员会仍试图启动公共紧急征用；白雪只以四方执行责任人的身份拒绝补上缺失授权并隔离接口，不拥有单人裁决权。系统只能显示新生方案启动，不能显示永生成功；罗凯失去最后一次剂量，地球是否仍有人等待也不揭晓。

## V9历史设定摘要（供V10继承核对）

> 本节保留旧版演化记录。V9中“成年人等待七至八年即可适配自续”“一百七十三例均为单次桥接”等设定已被V10废止，不得回填现行正文。

- 2048年发现的是C-9早期调查远航器投放的无人医疗着陆舱，不是完整星舰，所以没有遗体，也与地球人类祖源无关。
- 远航器在C-9人体试验五年后、第一代供体成年前出发，所以残片中的知识真实有效，却没有白潮、自续和文明后果。
- C-9距太阳系约十五点二光年，是海洋覆盖率约百分之九十五的独立生命世界；“C-9”是人类编号。
- 阿卡迪亚载员四万八千人，地球参考系航程约十八至十九年，船内约十年。
- 白雪是全书主角：她受顾棠影响主动选择审计，第15章放弃九十天有限升级并驳回早期异常关联，第17章已取得独立于许渡档案的阿卡迪亚条件船位，第36章签署停止提取，第73章在已知完整历史后签署四十八例数据确认，第79章保留两份相反签名，第80章签署儿童保护规则但不越权裁决具体生育申请。
- 许渡出身贫困供体家庭，经补偿教育成为阿卡迪亚闭环水循环与地下管线的专业运行工程师；他与白雪相识时职业能力接近，差距主要在资产、权限、医疗通道与灾难安全网。
- 白雪与许渡是明确的深度友情，不设置暧昧、未说出口的爱情或“差一点在一起”。许渡把完整档案的保管与语境异议权交给白雪，医疗和身后事务仍由本人及家人决定。
- C-9自续适配人类需要七至八年，阿卡迪亚抵达后只剩约四年医疗冗余。库存没有算错，缺口来自出发前未知的新技术条件。
- 船上先通过四十八例严格限定的新生提取，随后例外扩张到一百七十三例；真实获救与真实伤害必须同时成立。
- 首例复稳的第一名供体岑青以长期随访对象登船；她在四十八人名单锁定时尚未达到门槛，随后成为第四十九名患者并死亡，使“受害偿还”成为扩案最难抵抗的理由。
- 林岫与艾澈从船生同伴、四十八例听证中的分歧者，走到共同随访一百七十三名供体；他们保留分歧并成为伴侣，终章的生育申请不是临时配对。
- V9允许不推动主线的平叙、闲笔和一次性时代切面；不是所有人物都必须并入主角关系网或在后文回收。祁昼与苏弥是白雪在顾棠审计训练班的同学，必须从普通同学生活写到婚礼特写、冷冻选择与地球余波；岑青则因承担核心因果持续铺垫。
- 终章停在后来者的生育与政治申请“受理中”，不宣布文明获救。

## 章节结构

- **序章《地层之下》：** 三战中的遗迹争夺、白硕救韩真、异星尸骸与多方镜像存档；只证明死者来自C-9，不提前揭露其阵营和殖民目的。
- **第一部《地球》59章：** 上篇先用4章完成公开试验与十年成功，第5章起进入联合大学和五人组的连续生活；下篇33章完成三种病程、因果承认、停止决定、记录制度、长生海与离港。
- **第二部《无人城》41章：** 第60章直接抵达C-9；依次写空城探索、两个年龄的战争、地球残骸中死者的身份、留守与返航，最终在返航船的十小时出生窗口收束。
