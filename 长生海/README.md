## v7锁定的核心改动

- 2041—2048年第三次世界战争重创旧世界；停火后的联合清理与考古人员在地球古代遗址下发现一艘已经埋藏数万年的外星小型飞船残骸。残片没有外星文明史和完整续生说明，只留下损坏的急救生命模块、部分材料与导航原理，以及一个可校准方向C-9。
- 遗星研究经历战后封存、有限合作和公开遗星三个阶段，不存在三百年所有人共同守住同一个秘密的超级阴谋。
- 三战后地球没有统一政府，而由多个区域共同体、自治城市与跨域机构并存；发射前全球人口约十三点八亿。地球协调议会能够建立认证体系，却不能直接命令所有地区，这也是红色警报无法一键关闭全球的制度基础。
- 人类直到二十四世纪初才完成生命模块的跨物种解译。真正需要等待三十至五十年供体对照时，伊莲娜、关键工程和不愿死亡的掌权者都已经等不起；五年真实安全因此被错误地扩成长期放行。
- 残片教给人类的是“稳态重建”原则，不是现成药物。人类自行在人类新生儿出生十小时内识别初赋，并把最初的复稳治疗扩大成健康续生。
- C-9只是残片末次导航缓存中的唯一可靠方向。它可能是母星、研究站、补给节点、上一站，也可能已经没有任何可用信息。人类出发前不知道那里有巢滩兽、地下城市、三重圆文明史或自续技术。
- 阿卡迪亚原本就是人类深空联合署建造的第一次载人恒星际探险、定居验证与文明备份任务。白潮只增加医学希望、患者队列和出发压力，不把它改成临时逃生艇。
- 阿卡迪亚主舰在地月高轨联合船坞分段建造；地面“发射城”只是等比例验证区、乘员训练城与模块运输节点。T-19的“居住环合拢”指高轨结构骨架完成，T0的“发射”指主舰脱离船坞、转入离境轨道，不是整艘飞船从地面升空。星际档案只能经阿卡迪亚目的地相干光阵列与太阳系预建C-9定向接收网传送，单程仍需十五点二年。
- 阿九与衡一不再是早年抵达C-9并把档案送回地球的前驱机器人。它们由阿卡迪亚携带，抵达未知C-9后才执行地表调查；原有抽烟、中国功夫和不杀穿繁殖滩的幽默场景因此移入真正的探险段。
- 机器人只找到繁殖滩与钢门，无人城拒绝只认证机器。白雪、杜蘅、白远山、林岫等人必须亲自进入医院、住宅、学校、远航坞与公民厅，才能把三重圆文明拼回来。城市AI不代替人类念出文明结论。
- 地球篇以许渡的一生为中心：五岁把伊莲娜重新站起来记成文明常识，童年因供体补偿真实受益，十六岁见过亲人带着康复计划死去，二十八岁发现自己曾是初赋供体，三十二岁得到一至三年的明确死期，三十五岁已衰老并完成白潮证词。他拒绝新增供体与无限期冷冻，在阿卡迪亚发射前去世。
- 许渡先后只使用A、B及半份C剂量，共2.5个标准当量，全部来自不可返还的既有库存；他后来拒绝的是需要持续新增供体、而疗效仍会递减的未来续用方案。
- 许渡不是单人破解世界的天才。他的完整人生记录负责把时代之痛钉到一个人身上；杜蘅完成临床链，白雪取得制度证据，顾棠恢复反对记录，韩真与白远山承担历史责任。
- 白雪是许渡的爱人与后两卷承重人物。她保持年轻既来自阶级位置，也来自父亲未经充分同意安排的低剂量续生。她在地球红色警报和C-9有限恢复采集中分别承担四方联签的数据追溯栏；两份方向相反的个人签名构成她的一生，但她不是一人控制文明的生物钥匙。
- C-9确认地球残片来自三重圆文明在初赋转移早期发出的远航器。飞船离开时第一代供体尚未成年，所以残片中的短期医疗知识真实但过早，并非外星文明故意布置的骗局。
- 初赋只在同物种之间具有完整协调作用；C-9巢滩兽的白色兽卵是当地物种独有的生命循环，不是可供人类替代婴儿初赋的药源，正文不为此另开技术支线。
- C-9“居民为零”不等于三重圆物种确认灭绝。后来者消失以后，活够的人陆续停续，仍想继续的人驶向星际深处；AI维护的是被整体离场的故乡，远航者是否仍在宇宙某处保持未知。
- C-9存在自续，但人类抵达前完全不知道。适配需要七至八年，船载现场冗余只有约四年；四十八例随后增长为一百七十三例，证明人类即使已经读过许渡的记录，仍可能以眼前救人的理由重复旧制度。
- C-9的一百七十三个单位分别对应一百七十三次复温、手术或器官重建的单次桥接，不是年度续生订阅；常规治疗成功者退出初赋队列，失败者仍可能死亡，因此数量账不再暗示一百七十三个单位能支撑整批患者四年。
- 航程末尾不安排地球影像追上阿卡迪亚。叙事直接切回地球，让读者看见数百万座黑色冷冻舱，再切到C-9黑色潮滩上密密麻麻的乳白色兽卵；两幅画面在章节上相邻，船上人物并不知道地球后来发生了什么。
- 高层线不只是伦理会议，而是围绕“谁有资格被定义为不可替代”持续三十年的权力斗争。白远山要保住解译与女儿，伊莲娜要保住阿卡迪亚工程，韩真试图用继任人、年度复审和窄授权阻止席位永久化，雷蒙德则把供应、融资、急救和远航绑成一条任何人都不敢切断的链。
- 雷蒙德是明确的主观恶线：他本人已成为高剂量依赖者，在地球明知后批准“去反查”、利用黑市，红色警报后仍为自己接受一份新近非法提取的无法反查剂量。被起诉后，他以受监管待审高剂量样本转移到阿卡迪亚羁押区，没有船内表决权和任务权限。抵达C-9后，他利用外星公共接口无法识别人类羁押身份的漏洞，故意隐去排斥未出生者的附录。即使他从未拥有投票权，一百七十三例仍由普通合法多数通过；恶人不是整个文明的替罪羊。
- 自续只能终止未来依赖，不能复活许渡、返还冷冻年月或修复所有既有损伤。结局不宣布人类获救，只让后来者第一次正式进入资源与政治安排。

## 章节结构

- **序章《地层之下》：** 2048年三战停火后的遗星发现，只呈现物质事实与普通发现者被档案抹去，不写成秘密基地阴谋片。
- **第一卷《代际吞噬》42章：** 严格顺叙。前17章从五岁写到二十八岁，让家庭、学校、朋友、大学、工作、爱情与阿卡迪亚先成立；第18章才进入病程，第32章才明确一至三年的死亡窗口。上层实验、五年扩大、轻微信号、明知后拖延与库存远航逐年落到许渡身上。婚礼、死亡与发射彼此错开。
- **第二卷《同船者》14章：** 十年船内社会与首次C-9探险；阿九、衡一找到繁殖滩和钢门，主要人物亲自进入居民为零的城市。
- **第三卷《后来者》14章：** 四年库存对八年适配、四十八例增长为一百七十三例、自续成功、两份签名与后来者生育申请。
