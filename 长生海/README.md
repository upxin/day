## 人物与设定要点

- 许渡是地球篇的生活与情感中心；28号是C-9历史的人物中心。
- 白雪连接两代与两个文明，远航寻找旧供体的解法。
- 韩真与白齐山同岁。白齐山患癌获救后持续使用，韩真从未使用，外貌年老。
- 七岁黑豹与亲近者患癌的经历归韩真，集中在中段回忆，不直接解释表决。
- 韩真的承担不能保证及时救回许渡。完整使用账与私人库存放在回忆后展开。
- 保障早期部分兑现，危机时关键救助迟到；犯罪清查不能代替对合法决策的追问。
- 阿卡迪亚先作为独立工程存在，白潮后才改道，白雪、林微此时进入任务。
- 新生方案不能救成年人或旧供体。离港后不返回地球确认结局，通信沉默不代表灭绝。
