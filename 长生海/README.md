## 核心设定摘要

- 地下遗迹是C-9成年续生派约一万二千年前驶向地球的殖民船残骸。乘员死于太阳系减速阶段的结构—姿态系统级物理事故，不是宇宙惩罚。
- 初赋只在出生后约十小时内以游离态短暂经过血液，并被全身组织迅速吸收；闭合循环只能截留仍未嵌入组织的部分，血液与液体全部回输。十小时后窗口永久关闭。30%指对可分离游离池的标准截留比例，不是婴儿血量，也不在正文中折算成精确毫升数。
- 同一制剂既能配合常规医疗完成一次严重疾病复稳，也能使健康成年人停留在当前生理年龄约一年。治疗通常结束，停龄却每年自动产生新需求。
- 30%供体童年和青年期大多正常；约55%—70%在成年稳态重索引时进入白潮。早发症状不同，未经复稳或低温干预的典型患者都在三十六周岁这一生理年终末崩解。
- 人工合成只能复制局部信号。人工子宫可以孕育生命，但生成的初赋平均质量更低、连续性更差，不能成为可靠工业药源，也不能替人类完成新生自续的长期验证。
- 六年试验数据真实，伊莲等患者获救真实，100名供体儿童当时健康也真实。灾难来自把“六年内安全”外推成“一生安全”，不是靠伪造才能成立。
- 公众从一开始就知道治病与年度停龄两种用途，也知道一剂对应一名新生供体；绝大多数供体家庭拥有明确的授权与执行记录。后期未知是供体成年后果及制度在已经出现风险后为何仍不停止，不把“究竟有没有被提取”当作主要悬疑。
- 黄金扩张期单年峰值约60万—65万名供体，占当年出生人口约75%—80%。累计供体约850万—1000万，预期白潮患者约470万—700万。“八成”只指峰值出生代或特定覆盖区。
- 雷蒙在因果信号增强后拖延联合统计、转移私仓、牟利并经营黑市，是真正有主观恶的人；但合法制度先于他存在。审判他不能清偿其他签字者和整个社会的责任。
- 2130年六方共同承认因果，却没有统一永久停抽：暂停、旧库存、重症例外、关键岗位过渡和失踪批次同时存在。2136年地球仍在讨论最终处理。
- 长生海固定设计容量为2000万，2136年实际启用约110万—140万。已入舱者主要来自2094年试验队列、2100—2106年前期扩张队列及少量明确早发者；更年轻的大规模供体代仍处在登记、监测和预留阶段。它依靠标准化低代谢玻璃化舱、区域聚变电网、储能和被动隔热滚动建设，维护劳动与能源优先级必须进入剧情。
- 王远选择清醒生活，在三十六岁死亡；周开三十一岁进入地球长生海；从小明知自己是标准供体、却尚未发病的罗成，在风险重估后进入阿卡迪亚患者低温舱，并以间歇低温走完C-9与返航线。三种去向分别是死亡、留在地球等待和带着求生欲远航。
- 白雪出生时未被提取，成年后主动接受疾病复稳和短期年度停龄。她不是无辜旁观者；她的核心弧线是从相信正确数据会自动产生正确决定，走到承担自己每一次关门、签字和删节。
- 阿卡迪亚约载4.8万人：约1.8万名健康船员、研究者与定居人员清醒工作，约3万名患者和高风险供体低温远航。白雪、林微微、杜衡清醒；罗成以间歇低温和少量旧库存承担有限任务；白齐山、伊莲等长期依赖者去程主要沉睡。全船只带公开登记、用途受限的旧库存，足以处理少数清醒任务成员与紧急复稳，不足以覆盖全部患者或一次完整返航。
- C-9战争时期已经开始新生自续试验，但逃亡船离开时只有数年短期数据，既没有一代人的成年结果，也没有成熟的便携执行模块。成年人永远不能转轨，许多依赖者判断自己会先于验证完成而衰老或断供死亡。
- 逃亡者没有删掉一项已经成熟的救世技术。他们因等不起而带走当时唯一能够确定延续成年人生命的初赋库存、提取设备与殖民生育方案；留在C-9的人后来才完成新生自续的长期验证。
- C-9大型出生阵列为人类生成高风险适配模型，并制造一套尚未完成人类长期验证的便携模块。返航船启动第一例人类新生自续，但不以“已启动”冒充成功，更不宣布人类已经获得永生。
- 2154年以后的冲突是：成年人不存在脱离新生供体的自续解法；有限旧库存无法让所有患者返航；模块化阿卡迪亚把定居环与多数低温舱接入C-9，返航环则带着失败、技术和活着的见证者返回地球。
- 返航末段，库存危机使“最后一次例外”重新出现。返航共同体通过新生完整权条款，明确禁止为治疗成年人或维持任务而提取船生新生儿的初赋；白雪拒绝交付提取密钥，是执行共同规则，不是替全人类独自决定。
- 终章停在孩子哭声、自续系统“已启动”和逐渐变亮的太阳。船上的禁令已经成立，地球是否永久停止提取仍保持未知。
