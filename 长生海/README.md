## 本版已锁定的核心因果

- 故事发生在远未来地球，T-0人口约7.2亿。地球至C-9约15.2光年，普通人的一生不足以完成远航、长期考察和返航，因此续生具有真实的文明需求。
- C-9外层档案提供错误但有效的夺赋方法，第二道门保存代际灾难与复赋原理；M-7无人AI世界保存洁净复赋和三重圆文明最终停止延续的历史。
- 初龄质先用于多器官衰竭、辐射损伤等严格救命适应症，逆龄是后来发现的结果；十年真实安全、提取后循环浓度恢复和普通患者获救共同推动扩大，不能写成发现永生后立即猛抽。
- 采集只需覆盖同期约一成新生儿。少数国家允许采集，更多国家禁止本地采集却允许进口和使用；真正全球化的是收益，不是采集。
- 阿卡迪亚号是提前四十多年立项的真实C-9科学殖民船。核心层在T-4预测白潮后，只秘密改变航向、超额库存和未来分离权限，借走了已经建成的人类未来。
- 初赋是生命建立独立闭环时的全身定标；初龄质是可转移的定标载体，不是单一分子或生命燃料。
- 初龄质不直接构成年轻组织，而是让接受者的衰老细胞、干细胞、免疫与器官时序重新趋向青壮年稳态。
- 供体不是从小衰弱，而是在跨过临界值后先出现伤口过快愈合、广谱抗病毒激活与多发过敏的返照期，随后进入白潮。
- 再注射初龄质可以稳定白潮，但只能把有限供给从下一代转给当下患者，不能作为社会解法。
- 冷冻只能大幅降低定标耗散，不治疗、不停止物理时间，也不保证唤醒。
- M-7技术不合成生命本源，而是让活着的接受者从自身再次完成复赋，从而打断供体依赖。
- 星际间不使用可靠的数据传输；完整档案、医学资料与责任证据只能由实体归航器或载人飞船携带。本地信标只在行星系内有效。
- 人物采用五个不同的时间位置：许渡承担身体时间，杜蘅承担临床时间，白雪承担制度时间，韩真代表能够等待的人，伊莲娜代表不能等待的人。许渡与杜蘅是连续双主角；白雪贯穿责任档案线；韩真与伊莲娜只在文明岔路口取得历史重量，不扩写成全知主角或简单善恶对照。
- 续生始终不等于物理不死：意外、战争、大脑毁损、能源极限与宇宙熵增仍然存在。
