# 《长生海》写作目录

> **现行正典：V14·高开接力版。** 第一章从生命稳态研究项目公开会起笔：记者追问韩真为何既是最后一名反对者，又是最早、最年轻的续生者。三章历史写癌症患者死于等待、伊莲因冒险真实获救，以及韩真与白齐山在短期安全和长期未知之间作出的选择；第五章回到同一秒，由生命科学研究生许渡根据自己的人工替代实验追问每一支续生药对应的出生账。

全书统一走向为：

> **续生引起向往与疑问 → 繁华生活、科研项目与爱情共同生长 → 异常落到具体身体 → 提取代价与续生账曝光 → 长生海与远航把人物分开 → C-9分别走向停止与继续 → 新生长生最终实现，却不能救旧供体 → 答案与记录发往沉默的地球。**

## 全书结构

1. **第1—5章：年轻的老人。** 记者高开，随后连续三章写韩真与白齐山共同经历的研究历史：有人死在等待中，有人因复稳重新站起来，100名供体又连续多年处于正常范围；第5章回到公开会同一秒，由许渡把问题递给下一代。
2. **第6—14章：世界正午。** 许渡是生命科学研究生，也是这部分的生活与情感中心；他与白雪、林微、罗成在一个普通的跨实验室研究项目中成为朋友。人工替代实验始终无法达到临床质量，这才使许渡的出生账问题成立。流浪狗、贷款烧烤、回家吃饭、有窗的房子与爱情把普通生活立住，黑狗和少年病房只作为许渡人生的一部分出现，不解释成命运预告。阿卡迪亚此时只是新闻中的独立深空工程，与四人的学业和去向无关。
3. **第15—22章：身体先知道。** 不孕与多系统异常由正常医学网络逐步连接；原始100从第一人死亡走到100/100，韩真公开承认“六年只能证明六年”。
4. **第23—30章：续生账。** 出生时承诺的供体保障仍然有效，却被因果认定、调用名单与伤残审核层层延期；八千万供体、年度消耗、雷蒙犯罪、父亲私藏库存和停抽争议依次公开。许渡没有等到制度承诺的药，却接受了白雪从私人库存拿来的药。
5. **第31—40章：长生海。** 林微与罗成结婚，记忆记录制度建立；首期黑色舱群无法立刻接住所有人，随后转入不封顶的持续扩建。许渡因身体已经无法耐受低温而死亡；他的母亲带着迟到的批准继续生活并帮助其他家庭。白潮迫使原定去M-7的阿卡迪亚改道C-9，白雪和林微到这时才因研究与患者身份进入遴选。韩真留在地球，阿卡迪亚在停抽尚无结果时离港。
6. **第41—42章：两岸之间。** 白雪使用父亲暗藏库存，林微死于途中；地球黑色冷冻舱与C-9白色兽卵完成视觉接力。
7. **第43—54章：无人城。** 人类先确认主城居民为零，再从供体伤害已被确认的节点进入C-9历史。停止区跟随旧供体岑，证明停止和保障能够阻止新增伤害，却救不回旧供体；继续区用26号、28号、保护区和断供走向战争。逃亡船离开以后，新生长生方案才获得成功，后来者走向星际，主城因此空置。
8. **第55—56章：来处。** 确认地球遗迹与C-9逃亡船是同一艘船；白雪找到只适用于出生窗口中新生儿的长生方案，也确认它救不了任何成年人和旧供体。答案与那一代人的记录继续发往沉默的地球。

## 人物关系锁定

- 韩真与白齐山承担第一代决定线。他们都看见癌症患者在等待中死亡，也看见复稳配合既有治疗真实救人；韩真更早担心长期未知，却仍签过最后一票并接受过续生，白齐山更相信受控放行与未来替代技术，后来也利用权力为女儿私留库存。
- 许渡是生命科学研究生，也是地球篇的生活与情感中心。他研究人工复稳材料与组织修复，知道人工替代的质量和产量远未达到宣传中的未来，因此有专业根据地追问出生账。他嘴贫、现实、重钱、会做事，讨厌空话，真心想过普通日子；他会把同情做成具体方案，也会计算自己的续生资格。他质疑分配逻辑，却同样害怕死亡，发病后接受药，临终仍求下一支。
- 白雪是贯穿人物，不与许渡争夺情感中心。她把公共研究、父辈历史、自己的身体和许渡的命运连接起来，并承担给药、自己用药、登船和发送完整记录等具体选择。
- 白雪与许渡是地球主爱情线；爱情不负责把任何一个人写成另一个人的救世主。
- 林微与罗成是重要配角。林微被提取、罗成没有；他们以衰老者与年轻人的外貌结婚，后来一个登船、一个留守。
- 雷蒙是真正罪犯，但不是白潮起因。
- C-9的26号与28号没有血缘关系；26号之死把28号推向激进派，却不替他后来扣动扳机免责。
- C-9旧供体岑生活在停止区。他得到真实保障和认真治疗，仍然等不到适用于自己的答案；他的作用是证明“停止有效”与“已经发生的伤害无法撤回”能够同时成立。

## 技术与规模锁定

- 初赋只在出生后约十小时内可分离；合法供体使用统一标准程序，不设人为剂量档位。
- 治病可以阶段性结束；停龄必须每年使用。
- 公众知道初赋来自出生程序，也知道续生存在；不公开的是完整使用名单、供体对应账、健康使用者比例和年度消耗。
- 合法供体出生时被承诺终身随访、相关损伤优先救治和生活保障；儿童期体检与补助确实兑现过，白潮后关键保障却被拆进不同资格体系。条款仍有效，不等于救助真正到达。
- 原始100最终100/100死亡，锁定标准提取与白潮的长期因果。
- 合法供体约八千万，实际可能接近一亿；长生海首期约两千万舱位，离港时尚未完成，后续以接住全部适宜低温的存活供体为目标持续扩建。
- 完整保留初赋只保证正常一生，不会自动长生。必须在出生窗口关闭前额外完成自体稳态重构，新生儿才会在成熟后停止常规生物衰老。
- 成年复稳只能延缓衰老和失稳，无法建立永久稳态。
- 新生自续不能补做，不能救成年人和旧供体，也不等于物理不死；事故、暴力与宇宙尺度的毁灭仍可终结生命。
- C-9逃亡船离开时，新生自续尚未完成验证，因此地球遗迹中不存在成熟答案，不涉及逃亡者恶意删除答案。
- 供体保障即使全部兑现，也不能消除婴儿无法同意、损失不可逆这一层原始伦理问题。
- 地球沉默不代表人类灭绝。白潮一代可能已经进入扩建后的长生海，未被提取者、其他世代与维护系统仍然生活在地表；具体结果留给返航。
