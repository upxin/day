## v6已锁定的核心因果

- 人类正文从T-3阿卡迪亚开放参观与许渡异常愈合开始，沿许渡—杜蘅—白雪的连续现在时推进。第一卷只有第7章由白远山进入一次完整回忆，回答“人类为什么开始”；五年真实安全、十年争议信号、T-4知情责任与产业扩张只通过当下病例、审计、记录和活人对撞进入。标准剂量供体在三十五岁上下进入白潮后，会在一至三年内迅速衰老并死亡。
- 科学只是伦理困境成立的条件。故事的主体是现存者如何把自己的时间成本转给后来者。
- C-9外层档案只把材料描述为恢复全身稳态的医疗介质，人类最初称其为“复稳质”。五年随访后，人类自行发现续生效应并改称“续生质”；救人使制度开始，续生使制度无法停止。
- 续生质只能从出生十小时内的新生儿初赋过程分离，不能人工合成；标准单位约分离初赋可用总量的一半，可维持一名健康成年人约一年。闭合循环处理的是约半个血容量，不是抽走一半血液；人工子宫孕育出的来源质量过低，不能成为制度性替代。
- 供体短期指标真实正常，标准及高剂量供体在三十至四十岁出现问题的比例约为50%—70%，且剂量越高风险越大。
- 续生只能把受体维持在开始稳定使用时的生理年龄，不能返老；停用后从锁定年龄继续衰老，不会瞬间追上日历年龄。
- 长期使用者停止后多数不会立即死亡，而是重新衰老；高剂量依赖者和白潮患者可能快速失稳。库存冲突因此同时包含生命、权力、事业和不肯老去。
- 白远山、韩真和伊莲娜都不是简单好人或坏人：他们分别承担恐惧、合法放行与续生权扩张的责任。
- 雷蒙德是现行正典中的具名反派与产业扩张发动机：他先建立具有公共价值的跨区急救与保存体系，再以供体补偿基金、医院未来库存合同和受体连续权，把有限救治变成由既有承诺驱动下一年抽取的产业；T-4明知风险后，他又转移库存、拆分责任链并组织跨辖区续期。他在危机前已通过匿名分层抽签进入弹性医学观察预选，红色警报后该队列才整体转编为高依赖纵向队列；揭名后因尚无生效判决保留席位，却失去职务、资产和全部旧系统权限。抵达C-9后，他推动四十八例向一百七十三例扩张并最终接受自续。没有他规模不会相同，清算他也不能让制度自动停止。
- 白雪是贯穿全书的承重人物。她先在地球签署红色警报，使主流新增采集失去合法入口；后在C-9为等待正确技术签署有限恢复采集。两份签名共同构成她的一生，但她从未拥有一键关闭全球或独自决定全船的权力。
- 阿卡迪亚是真实、公开、合法的C-9任务，不是临时逃生艇。它在白潮以前已经拥有地外文明研究、恒星际定居和文明备份任务；白潮后来增加的是寻找供体替代技术的医学必要性。C-9也不是骗局。
- 四万八千定员在危机前已经确定：约四万零四百名核心任务人员、定居者与家属不因危机撤销，七千六百个长期适应、轮换定居和医学观察弹性席位在红色警报后被重编为白潮纵向队列与高剂量依赖者。阿卡迪亚是一座城市，不是四万八千张临时船票。
- 地球在阿卡迪亚以前发射过无人工程前驱；它只能完成外部测绘和接口固定，无法携带城市级制造链、长期活体队列与完整临床体系。阿卡迪亚带走的是能源、工业母机、封闭生态、医院、病例库和知识系统共同构成的科技再生产能力，不是AI突然失去工作能力，也不是一份抵达C-9后才出现的万能设备清单。
- T-0不存在错过便永远不能起飞的虚假天文窗口。阿卡迪亚可以延期，但每一年都会重新消耗任务库存、淘汰正在恶化的纵向队列并推迟C-9答案；韩真放行仍是人的选择，不能让物理定律替他免责。
- T-0全球登记长期续生者约四十一万，阿卡迪亚只带走四万八千人。四万八千是发射人口，不是生态极限；五千二百名冷冻者降低初期活动负荷，封闭生态的稳定活动人口上限为六万，航程出生与抵达后的数千名后来者因此有容量依据。
- 船上二万二千个标准当量中，十年航程计划消耗约八千八百，抵达时余约一万三千二百；C-9复温、采样与适配使年均需求升到约三千三百，只够约四年。真正危机来自自续需要七至八年人类适配，不是船员忘记计算航程药量。
- 阿卡迪亚以约0.84c巡航，船内经过约十年、地球参考系经过约十八年。地球在发射后二年十个月发送黑色冷冻舱影像，低带宽光束在飞船最后减速段追上；船员看到的是约十五年前的地球，并与舷窗外乳白色兽卵第一次形成对照。
- 巢滩兽不是三重圆文明的退化后裔，而是C-9现存的另一种高认知卵生哺乳动物；它们拥有复杂社会与有限工具行为，但没有被发现拥有符号文明。三重圆文明先从它们的代际行为识别可转移窗口，再把方法用于自己的新生代；外层档案封存时，第一代供体尚未成年。“居民为零”只指地下城市登记的三重圆居民，不指C-9没有生命。
- C-9第一份恢复采集授权以四十八名新生儿为上限。首案完成十一天后，原本未达门槛的玛拉因不可预见的生理崩解进入同等死亡风险，却未等到新程序完成；议会随后改组扩案程序。到自续成功时，实际共有一百七十三名船生儿童被提取。
- 林岫抵达C-9时约十岁，只能发现、倡议并要求未成年意见记名；永久废止外星信托的正式决定由成年临时居民议会和白雪签署。她的伦理重量来自理由被采用并成为先例，不来自越龄取得行政权。
- C-9第二道门后同时保存无人城、洁净自续技术和外星文明终局，不再另设M-7实体目的地。
- 自续只能终止未来依赖，不能复活死者、修复所有既有损伤或归还供体失去的人生。成人自续成功也不能自动证明婴儿期发育底图受损者能够在十八岁被完整修复，船生供体仍需独立的儿童与青春期验证。
- 结局不是外星文明审判人类，而是人类在知道全部历史之后仍必须自行决定：现存者是否愿意给后来者让出真正的位置。
