## V10关键设定摘要

- 三战发生在已经拥有月球工业、轨道城市与初步恒星际工程的未来时代；以阿卡迪亚离港为T0，遗迹争夺和白硕救韩真发生在约T-70，不再沿用V9的2041—2048公历。
- 地下遗迹是一艘严重解体的C-9载人殖民船，外星乘员已经全部死亡。人类能看见尸骸、黑色医疗舱和C-9方向，却无法从残存资料判断死者属于成年续生派，也不知道他们带着延续代际提取的殖民方案而来；坠毁原因始终不作唯一解释。
- 遗迹解译与战后重建持续近三十年，T-40启动首批人体复稳与十年滚动试验；前五年逐步入组、后五年停止扩容并继续观察，累计供体约十万。许渡等人于T-35进入后段队列，T-30公开十年分层数据和伊莲的十一步。
- 白雪不是幼年首例受体。她成年后在常规治疗、阿卡迪亚资格与合法复稳之间主动选择用药，因此仍是制度受益者，也必须承担自己的判断。
- 许渡、周野、罗凯通过公开的“终身底图教育通道”进入大型阿卡迪亚学院，林微通过普通选拔进入；五人在跨专业工程组相识，避免三个早期供体随机成为同一小圈子的巧合。
- 许渡死亡，周野与林微结婚后进入长生海，罗凯在母亲自杀后夺回船位并依赖库存远航；林微带着周野的记录登船。
- 记录制度只在地球篇高潮出现。长生海以连续数章完成，不在开篇提前展示规模和人物去向。
- “十年安全”是V10的人类认识论脊椎：最老供体随访十年、后段供体随访五年，分层数据全部真实，却仍被制度错误地外推到三十五岁。九十天复核、年度续针、低温等待与自续下限都要以不同形式重演“短期证据被改写成长期确定”的机制。C-9自身仍保留更早的五年安全历史，形成“人类多等五年，依然没有等完一代人”的对照。
- 白雪在船上以保护许渡尊严为由封存其临终求药记录，后被林微发现并公开解封。她因此不再只是犯过一次程序错误，而是会因爱再次控制别人语境的人。
- 阿卡迪亚本来是和平时代的恒星际探险、定居验证与文明备份工程，白潮使它同时成为求解船、病例船和部分高层的逃亡工具。正文在离港后直接越过约十个船年，以人物年龄、死亡空位和改变的关系表现航程代价。
- C-9历史只用少数关键章节呈现：当地文明也把五年真实安全扩大为成年续生制度，随后在出生中心、库存港和远航坞爆发屠杀与战争。成年续生派败退时带着库存、提取设备、繁殖人口名单和殖民方案驶向地球；正文不追写这段航行，只在C-9档案与地球残骸编号吻合时揭露身份。
- C-9新生自续只在出生十小时内、完整初赋尚未嵌入时成立；接受者正常长大，成熟后保持生理稳态。提取与自续不可兼得，同一个孩子只能保留自己的未来，或成为成年人一年的药。
- 初赋可以按比例分离，但不同供体不能在同一次疗程中拼接。成人复稳实行“单次疗程一源”：低于30%不能启动全身复稳，45%—55%为年度标准剂量；上一剂一年内降解后，下一年度可以更换新的单一供体，不存在终身认主冲突。新生自续要求至少保留95%的原生拓扑，因此成人有效剂量与自续条件没有重叠区。
- 供体伤害随净提取量非线性上升。许渡约54%、周野约60%、罗凯约49%，分别形成标准偏高早发、超量重症和标准剂量稍晚发病；同一比例仍会因遗传、感染、创伤和生活压力出现不同病程。
- 成年人的发育母版已经锁定，不能靠基因改写、器官置换或外源初赋重新进入自续。无人城因此没有许渡、周野、罗凯和长生海患者的解药；新生技术只能阻止后来者再次成为药，不能撤销已经发生的伤害。
- 白硕、伊莲、杜衡等人留在C-9恢复能源、保存历史并等待人类新生自续的长期证据；白雪、林微、罗凯、雷蒙等人返航，把真相而不是解药带回地球。返航船始终收不到可靠的地球回应，正文也不切回地球替人物揭晓答案。
- 返航末尾，安禾与陆青的孩子出生，罗凯恰逢急性失稳。提取设备和新生自续设备同时待命；白雪关闭提取接口，为孩子保留完整初赋。系统只能显示方案启动，不能显示永生成功；罗凯失去最后一次剂量，地球是否仍有人等待也不揭晓。

- 2048年发现的是C-9早期调查远航器投放的无人医疗着陆舱，不是完整星舰，所以没有遗体，也与地球人类祖源无关。

- C-9距太阳系约十五点二光年，是海洋覆盖率约百分之九十五的独立生命世界；“C-9”是人类编号。
- 阿卡迪亚载员四万八千人，地球参考系航程约十八至十九年，船内约十年。
- 白雪是全书主角：她受顾棠影响主动选择审计，第15章放弃九十天有限升级并驳回早期异常关联，第17章已取得独立于许渡档案的阿卡迪亚条件船位，第36章签署停止提取，第73章在已知完整历史后签署四十八例数据确认，第79章保留两份相反签名，第80章签署儿童保护规则但不越权裁决具体生育申请。
- 许渡出身贫困供体家庭，经补偿教育成为阿卡迪亚闭环水循环与地下管线的专业运行工程师；他与白雪相识时职业能力接近，差距主要在资产、权限、医疗通道与灾难安全网。
- 白雪与许渡是明确的深度友情，不设置暧昧、未说出口的爱情或“差一点在一起”。许渡把完整档案的保管与语境异议权交给白雪，医疗和身后事务仍由本人及家人决定。
- C-9自续适配人类需要七至八年，阿卡迪亚抵达后只剩约四年医疗冗余。库存没有算错，缺口来自出发前未知的新技术条件。
- 船上先通过四十八例严格限定的新生提取，随后例外扩张到一百七十三例；真实获救与真实伤害必须同时成立。
- 首例复稳的第一名供体岑青以长期随访对象登船；她在四十八人名单锁定时尚未达到门槛，随后成为第四十九名患者并死亡，使“受害偿还”成为扩案最难抵抗的理由。
- 林岫与艾澈从船生同伴、四十八例听证中的分歧者，走到共同随访一百七十三名供体；他们保留分歧并成为伴侣，终章的生育申请不是临时配对。
- V9允许不推动主线的平叙、闲笔和一次性时代切面；不是所有人物都必须并入主角关系网或在后文回收。祁昼与苏弥是白雪在顾棠审计训练班的同学，必须从普通同学生活写到婚礼特写、冷冻选择与地球余波；岑青则因承担核心因果持续铺垫。
- 终章停在后来者的生育与政治申请“受理中”，不宣布文明获救。

## v7备份设定摘要（不与v8混用）

- 2041—2048年第三次世界战争重创旧世界；停火后的联合清理与考古人员在地球古代遗址下发现一艘已经埋藏数万年的外星小型飞船残骸。残片没有外星文明史和完整续生说明，只留下损坏的急救生命模块、部分材料与导航原理，以及一个可校准方向C-9。
- 遗星研究经历战后封存、有限合作和公开遗星三个阶段，不存在三百年所有人共同守住同一个秘密的超级阴谋。
- 三战后地球没有统一政府，而由多个区域共同体、自治城市与跨域机构并存；发射前全球人口约十三点八亿。地球协调议会能够建立认证体系，却不能直接命令所有地区，这也是红色警报无法一键关闭全球的制度基础。
- 人类直到二十四世纪初才完成生命模块的跨物种解译。真正需要等待三十至五十年供体对照时，伊莲娜、关键工程和不愿死亡的掌权者都已经等不起；五年真实安全因此被错误地扩成长期放行。
- 残片教给人类的是“稳态重建”原则，不是现成药物。人类自行在人类新生儿出生十小时内识别初赋，并把最初的复稳治疗扩大成健康续生。
- C-9只是残片末次导航缓存中的唯一可靠方向。它可能是母星、研究站、补给节点、上一站，也可能已经没有任何可用信息。人类出发前不知道那里有巢滩兽、地下城市、三重圆文明史或自续技术。
- 阿卡迪亚原本就是人类深空联合署建造的第一次载人恒星际探险、定居验证与文明备份任务。白潮只增加医学希望、患者队列和出发压力，不把它改成临时逃生艇。
- 阿卡迪亚主舰在地月高轨联合船坞分段建造；地面“发射城”只是等比例验证区、乘员训练城与模块运输节点。T-19的“居住环合拢”指高轨结构骨架完成，T0的“发射”指主舰脱离船坞、转入离境轨道，不是整艘飞船从地面升空。星际档案只能经阿卡迪亚目的地相干光阵列与太阳系预建C-9定向接收网传送，单程仍需十五点二年。
- 阿九与衡一不再是早年抵达C-9并把档案送回地球的前驱机器人。它们由阿卡迪亚携带，抵达未知C-9后才执行地表调查；原有抽烟、中国功夫和不杀穿繁殖滩的幽默场景因此移入真正的探险段。
- 机器人只找到繁殖滩与钢门，无人城拒绝只认证机器。白雪、杜蘅、白硕与罗屿组成首批有机登陆队；约十岁的林岫只在安全确认后进入空学校。城市AI不代替人类念出文明结论。

- 许渡不是单人破解世界的天才。他的完整人生记录负责把时代之痛钉到一个人身上；杜蘅完成临床链，白雪取得制度证据，顾棠恢复反对记录，韩真与白硕承担历史责任。
- 白雪是全书主角，不是许渡死后才接班的后两卷承重人物。她保持年轻既来自阶级位置，也来自父亲未经充分同意安排的低剂量续生；她也曾亲手驳回证据不足的早期异常关联。她在地球红色警报和C-9有限恢复采集中分别承担四方联签的数据追溯栏，两份方向相反的个人签名构成她的一生。
- C-9确认地球残片来自三重圆文明在初赋转移早期发出的远航器。飞船离开时第一代供体尚未成年，所以残片中的短期医疗知识真实但过早，并非外星文明故意布置的骗局。
- 初赋只在同物种之间具有完整协调作用；C-9巢滩兽的白色兽卵是当地物种独有的生命循环，不是可供人类替代婴儿初赋的药源，正文不为此另开技术支线。
- C-9“居民为零”不等于三重圆物种确认灭绝。后来者消失以后，活够的人陆续停续，仍想继续的人驶向星际深处；AI维护的是被整体离场的故乡，远航者是否仍在宇宙某处保持未知。
- C-9存在自续，但人类抵达前完全不知道。适配需要七至八年，船载现场冗余只有约四年；四十八例随后增长为一百七十三例，证明人类即使已经读过许渡的记录，仍可能以眼前救人的理由重复旧制度。
- C-9的一百七十三个单位分别对应一百七十三次复温、手术或器官重建的单次桥接，不是年度续生订阅；常规治疗成功者退出初赋队列，失败者仍可能死亡，因此数量账不再暗示一百七十三个单位能支撑整批患者四年。
- 航程末尾不安排地球影像追上阿卡迪亚。叙事直接切回地球，让读者看见数百万座黑色冷冻舱，再切到C-9黑色潮滩上密密麻麻的乳白色兽卵；两幅画面在章节上相邻，船上人物并不知道地球后来发生了什么。
- 高层线不只是伦理会议，而是围绕“谁有资格被定义为不可替代”持续三十年的权力斗争。白硕要保住解译与女儿，伊莲娜要保住阿卡迪亚工程，韩真试图用继任人、年度复审和窄授权阻止席位永久化，雷蒙德则把供应、融资、急救和远航绑成一条任何人都不敢切断的链。
- 雷蒙德是明确的主观恶线：他本人已成为高剂量依赖者，在地球明知后批准“去反查”、利用黑市，红色警报后仍为自己接受一份新近非法提取的无法反查剂量。被起诉后，他以受监管待审高剂量样本转移到阿卡迪亚羁押区，没有船内表决权和任务权限。抵达C-9后，他利用外星公共接口无法识别人类羁押身份的漏洞，故意隐去排斥未出生者的附录。即使他从未拥有投票权，一百七十三例仍由普通合法多数通过；恶人不是整个文明的替罪羊。
- 自续只能终止未来依赖，不能复活许渡、返还冷冻年月或修复所有既有损伤。结局不宣布人类获救，只让后来者第一次正式进入资源与政治安排。

## 章节结构

- **序章《地层之下》：** 三战中的遗迹争夺、白硕救韩真、异星尸骸与多方镜像存档；只证明死者来自C-9，不提前揭露其阵营和殖民目的。
- **第一部《地球》59章：** 上篇26章让繁荣、学院五人组与阿卡迪亚真实成立；下篇33章完成三种病程、停止决定、记录制度、长生海与离港。
- **第二部《无人城》49章：** 第60章直接抵达C-9；依次写空城探索、两个年龄的战争、地球残骸中死者的身份、留守与返航，最终在返航船的十小时出生窗口收束。
