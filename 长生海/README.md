> **V10现行方向（2026-09-02）：** 全书为“地球篇＋无人城篇”，统一使用公历年份。2066—2067年发生遗迹战争，2094年纳入首批100名供体，2100年六年放行并启动首批扩张，2130年首批供体抵达三十六岁年龄墙，2136年许渡死亡、阿卡迪亚离港，2154年抵达C-9。阿卡迪亚零初赋库存，以寻找成人解法为第一任务；C-9最终证明成年人无解。2154年发出的完整档案最早约2169年抵达地球，地球此前和此后的选择均保持未知。

## 核心设定摘要

- 地下遗迹是C-9成年续生派约一万二千年前驶向地球的殖民船残骸。乘员死于太阳系减速阶段的结构—姿态系统级物理事故，不是宇宙惩罚。
- 初赋在出生后十小时内逐步被新生儿自身吸收并写入发育，不是凭空消散。人类用闭合循环分离约30%，血液和液体回输，一名供体形成一份标准制剂。
- 同一制剂既能配合常规医疗完成一次严重疾病复稳，也能使健康成年人停留在当前生理年龄约一年。治疗通常结束，停龄却每年自动产生新需求。
- 30%供体童年和青年期大多正常；约55%—70%在成年稳态重索引时进入白潮。早发症状不同，未经复稳或低温干预的典型患者都在三十六周岁这一生理年终末崩解。
- 人工合成只能复制局部信号。人工子宫可以孕育生命，但生成的初赋平均质量更低、连续性更差，不能成为可靠工业药源，也不能替人类完成新生自续的长期验证。
- 六年试验数据真实，伊莲等患者获救真实，100名供体儿童当时健康也真实。灾难来自把“六年内安全”外推成“一生安全”，不是靠伪造才能成立。
- 公众从一开始就知道治病与年度停龄两种用途，也知道一剂对应一名新生供体。后期秘密是具体流向、超额库存、删键、黑市和供体成年后果。
- 黄金扩张期单年峰值约60万—65万名供体，占当年出生人口约75%—80%。累计供体约850万—1000万，预期白潮患者约470万—700万。“八成”只指峰值出生代或特定覆盖区。
- 雷蒙在因果信号增强后主动拆键、囤积、牟利并经营黑市，是真正有主观恶的人；但合法制度先于他存在。审判他不能清偿其他签字者和整个社会的责任。
- 2130年六方共同承认因果，却没有统一永久停抽：暂停、旧库存、重症例外、关键岗位过渡和失踪批次同时存在。2136年地球仍在讨论最终处理。
- 长生海固定设计容量为2000万，2136年实际启用约110万—140万。已入舱者主要来自2094年试验队列、2100—2106年前期扩张队列及少量明确早发者；更年轻的大规模供体代仍处在登记、监测和预留阶段。它依靠标准化低代谢玻璃化舱、区域聚变电网、储能和被动隔热滚动建设，维护劳动与能源优先级必须进入剧情。
- 许渡选择清醒生活，在三十六岁死亡；周野三十一岁进入地球长生海；尚未发病的罗凯确认供体身份后，三十一岁进入阿卡迪亚患者低温舱。三种去向分别是死亡、留在地球等待和沉睡远航。
- 白雪出生时未被提取，成年后主动接受疾病复稳和短期年度停龄。她不是无辜旁观者；她的核心弧线是从相信正确数据会自动产生正确决定，走到承担自己每一次关门、签字和删节。
- 阿卡迪亚约载4.8万人：约1.8万名健康船员、研究者与定居人员清醒工作，约3万名患者和高风险供体低温远航。罗凯、白硕、伊莲沉睡；白雪、林微、杜衡清醒。全船不带初赋库存。
- C-9在战争前已经掌握新生自续：只在出生十小时内建立，接受者正常长大，成年后维持自身稳态。成年人永远不能转轨。
- C-9成年续生派明知新生自续存在，仍让部分权力家庭的新生儿获得自续，让另一部分新生儿保持可提取状态。他们逃亡时故意不带物种模型与执行核心，以便在殖民地维持供体阶层。
- C-9大型出生阵列能为未来人类生成高风险适配模型并制造便携模块，但本书不启动第一例人类新生自续，不以短期结果宣布人类永生。
- 2154年的冲突不是返航途中再次抽取婴儿，而是：不存在脱离新生供体的成人自续解法、约3万名患者不能被唤醒、原本按去程与有限基地转换设计的舰载能源无法承担百年保存、如何把患者接入无人城电网，以及是否在有限的高冗余发送窗口中把危险但完整的技术发回地球。
- 白雪最终支持发送原始档案、失败模型、相反意见与访问方法。她不能替地球决定停止，也不能替沉睡者或未来儿童作出选择。
- 本书不执行返航。终章停在全量信号离开C-9、患者继续沉睡、地球答案未知。
