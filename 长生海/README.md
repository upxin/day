## v6已锁定的核心因果

- 科学只是伦理困境成立的条件。故事的主体是现存者如何把自己的时间成本转给后来者。
- 物质统一称为“续生质”。它最初辅助治疗，后来主要用于健康续生；救人使制度开始，续生使制度无法停止。
- 续生质只能从出生十小时内的新生儿初赋过程分离，不能人工合成；人工子宫孕育出的来源质量过低，不能成为制度性替代。
- 供体短期指标真实正常，标准及高剂量供体在三十至四十岁出现问题的比例约为50%—70%，且剂量越高风险越大。
- 长期使用者停止后多数不会立即死亡，而是重新衰老；高剂量依赖者和白潮患者可能快速失稳。库存冲突因此同时包含生命、权力、事业和不肯老去。
- 白远山、韩真和伊莲娜都不是简单好人或坏人：他们分别承担恐惧、合法放行与续生权扩张的责任。
- 白雪是贯穿全书的承重人物。她先在地球签署红色警报，使主流新增采集失去合法入口；后在C-9为等待正确技术签署有限恢复采集。两份签名共同构成她的一生，但她从未拥有一键关闭全球或独自决定全船的权力。
- 阿卡迪亚是真实、公开、合法的C-9任务，不是临时逃生艇。C-9也不是骗局。
- 地球到C-9约二十年，飞船携带足够完成原航程并支持约四年现场工作的库存；真正危机来自C-9自续技术需要七至八年人类适配。
- C-9第二道门后同时保存无人城、洁净自续技术和外星文明终局，不再另设M-7实体目的地。
- 自续只能终止未来依赖，不能复活死者、修复所有既有损伤或归还供体失去的人生。
- 结局不是外星文明审判人类，而是人类在知道全部历史之后仍必须自行决定：现存者是否愿意给后来者让出真正的位置。
