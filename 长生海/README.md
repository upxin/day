## 知情层级

- **普通公众：** 知道初赋来自出生十小时内的新生窗口，能够配合现代医学治疗重病；相信短期试验已经证明程序安全。
- **医疗与伦理核心：** 知道重复使用可能维持生理年龄，但规则禁止健康抗衰，只允许极少数逐年复核的治疗性例外。
- **最高决策层：** 掌握续生名单与秘密配额。地球当下的冲突，是有人用“防止复发”“战略岗位连续性”和“停用会失稳”逐步扩大治疗定义。

绝大多数初赋在名义上和实际上仍用于真实救治，秘密续生只占少量配额。这样既不需要让庞大医疗工业共同保守一个不可能的秘密，也保留了真正的罪：一套为救人建立的制度，被少数人从例外处撬开。

续生最初从重症复发者的第二、第三次合法治疗中被意外发现。一次或少数几次正规救治不会制造终身依赖；只有健康或已康复成年人连续多年接受年度续生，才可能在停用后出现反跳性失稳。遗骸设备本身是能够读取宿主生命结构的适配平台，不是可直接用于人类的C-9成药。

## 不得回退的边界

- 罗成不是原始100，也不是三十五岁的师长型人物；他与白雪、许渡年龄接近。罗成与许渡是真实供体，白雪只是名义供体。
- 罗成当前只有先兆。他匹配的是原始100在相近年龄留下的旧样本，不是原始100当前的终末临床状态。
- 三十六岁不是生日机关，也不是100%必发；易感者约35岁进入明确白潮，通常在8—14个月内死亡。
- 全球累计供体暂按约8000万—1亿、综合发病风险约55%—70%锁定；因此是数千万人面临死亡，不是每一名供体都被宣判。
- 韩真历史固定十章。它只负责解释为什么治病成立、韩真与白齐山为何先反对后签字、续生怎样被发现以及人道边界如何被越过。
- 初次扩大不是单人阴谋。白齐山转向是因为禁止已经无法阻止失控使用；韩真最后签字既有患者和正常数据的压力，也有他自己的探索欲。历史推动他们，但不能替他们免责。
- 白雪是白齐山的女儿。白齐山与伴侣真实同意她进入扩大队列，却不知道韩真暗中让她保持零提取；她不承担供体型白潮风险，不使用预防性续生，也不占用长生海患者床位。
- 公众在韩真历史段不知道续生，不能出现全民公开的年度停龄产业。
- 阿卡迪亚不携带供健康成年人年度续生的库存，患者依靠提前低温。
- 长生海在阿卡迪亚启航时已经正式建立、一期运行，但主体远未建成；五个人中没有谁取得床位。罗成和后来发病的许薇薇都在候选队列里等到越过安全低温窗口。
- 五人中只有白雪前往C-9。许渡不是拒绝低温，而是医学上无法耐受长期低温；罗成、许渡、许薇薇先后死亡，未被提取的周野一直留在地球。
- 周野只是地面通信团队中整理和认证状态包的固定成员，正式阵列负责发送。白雪最后收到的地球影像早于三个人的死亡；后续记录可能失联，也可能仍在途中。五年断信只统计按航迹反推后本应抵达的认证序列，鸟瞰视频则是带日期的延迟压缩包，不是直播。
- 三个人必须分别死在自己的章节和日常生活里，不能合并成灾难数字；正文只写岗位、名单、门禁、复评、病程和关系，不替人物总结阶级寓意。
- C-9必须由具体人物直接生活，不能让AI替一整个文明作说明。
- C-9战争造成约95%登记人口死亡，但幸存者仍在机器主城之外生活；“无人城”不等于整个物种灭绝。
- 强制孕育与编号劳工只发生在C-9的一个制剂出口国；其他国家制度不同，却长期购买其制剂。出口断供和跨国干预把地方战争扩大为行星灾难。
- 结尾保留地球未知：校正光速延迟后连续五年没有新认证信息是事实，地球毁灭不是事实。
