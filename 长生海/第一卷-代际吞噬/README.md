## 卷内运动

序章把“代际吞噬”写成槐星上一段未公开的生物记录；地球正文先用阿卡迪亚号最后一段未封闭船壳打开一个真正繁荣、真正消灭大部分疾病、却仍没有消灭贫穷与衰老的世界。白远山三段回忆只打开C9-BIO-0041的效果、伦理反应和被限制的地球同源可能，不展示九十二秒完整影像，也不说明地球技术从什么生命阶段取得材料。程野负责让读者爱上这个时代，秦砺在第一章末写下他的姓名并接过现实时间锚点；第五章再揭示秦砺曾以医生身份为真实有效的生命底图公开背书，使他在不知情时把职业信用借给隐藏流程。林微与周艾分别代表专业未来和普通家庭。这里采用双轴叙事：配角可以比主角更讨人喜欢，白雪和秦砺仍然拥有所有改变因果方向的判断，并负责带着失去继续往前走。

卷末，周艾的孩子在合法生命底图流程中平安回到母亲怀里。没有死亡，没有立刻可见的伤害；读者只能看见家属与产科人员权限之外多出一行“LQ二级流程”，不知道它处理了什么、去了哪里。“代际吞噬”至此仍像一个只属于异星的词。
