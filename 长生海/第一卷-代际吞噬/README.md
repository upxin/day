## 卷内运动

序章把“代际吞噬”写成槐星上一段未公开的生物记录；地球正文则展示一个真正繁荣、真正消灭大部分疾病、却仍没有消灭贫穷与衰老的世界。白远山三段回忆逐步打开C9-BIO-0041，秦砺陪程野走进阿卡迪亚号，林微与周艾分别代表专业未来和普通家庭。

卷末，周艾的孩子在合法生命底图流程中平安回到母亲怀里。没有死亡，没有立刻可见的伤害，只有一只匿名冷链匣离开产房。“代际吞噬”至此仍像一个只属于异星的词。
