# 人物爬升与行动链

> 人物档案见 `01-核心人物`；章节节点见 `09-人物线索总表` 与 `02/03` 目录。本文件只厘清两人"为何能介入"与爬升的代价结构。

## 基本判断

两人不能"两个普通人推翻国家"。他们能介入，是因为本就在同一条续生供应链上，只站最底端（秦砺）与较高端（江照雪）：

```
新生儿十小时窗口
  → 源民区医院 / 出生登记
  → 冷链转运与样本编号
  → 提纯 / 临床验证 / 续生处方
  → 续生席 / 军政决策 / 长生海名单
```

- 秦砺在第二、三环之间：跑冷链、改预约号，看得见"谁被带走、什么被运走"。
- 江照雪在第三、四环之间：负责白潮病例与续生临床审核，看得见"什么药进谁身体、哪些数据被删"。

单独都只看到半条链；合作才接起出生 → 物流 → 病理 → 名单。

## 江照雪的爬升（每次上升都有代价）

- **起点**：源民区妇幼中心夜班分型医师，有门禁无人脉，无配额 / 安保 / 资金。
- **第一次上升**：白潮专案组临床联络官（获得跨院调阅权；代价：记者会重复官方口径）。
- **第二次上升**：出生医疗清查负责人（获得十小时记录解封权；代价：签字允许军方封控下继续筛查，秦砺第一次不信任她）。
- **第三次上升**：长生海临时医疗总监（获得名单复核权 / 医疗舱钥匙；代价：必须上船、被秦砺怀疑"爬进他们那一边"）。
- **终点**：把两张纸交别人——他的船票、证据的可信度——然后转身（详见 `01` / 第 24 章）。

## 秦砺的爬升（从跑腿者到断线者）

- **起点**：冷链配送员与信息掮客，替医院 / 药贩 / 源民家庭跑单。
- **第一次上升**：灰名单持有人（第一个证明"药物—婴儿—白潮"关联）。
- **第二次上升**：源民区谈判者（组织家庭拒交新生儿、保护证人）。
- **第三次上升**：长生海名单变量（掌握源场名单，迫使委员会接受他登船；船票是他挣的，密钥是她给的，见 `09-〇`）。

## 两人共同改变的三件事（第一部边界）

1. 让真相进公共记录，断掉"自然灾害"谎言。
2. 把长生海从完全由延续体制控制的逃生船，撕开可反抗的制度缺口。
3. 阻止源民区家庭被整批运往飞船成为新出生供应链。
