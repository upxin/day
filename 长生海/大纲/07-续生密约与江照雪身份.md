# 续生密约与江照雪身份

> 世界观机制见 `00-项目总纲`（续生密约 / 初龄质）；江照雪人物全档见 `01-核心人物`；登船方式锁定见 `09-〇`。本文件只留密约的政治逻辑底线与江照雪身份要点。

## 续生密约：不是统治阶级，是藏在缝隙里的少数人

真正掌握初龄质的不是公开政府，而是人数不超两百的秘密网络"续生密约"。成员间不共享全部初龄质，只交易配额 / 情报 / 保护 / 人情债。它不像纪律严明的组织，更像一群互相需要又互相防备的旧人。

## 密约不是国家：三层逻辑（全书政治底线）

**绝不能写成国家顶尖权力的整体犯罪。密约是部分人的有意而为。**

1. **船是国家造的，票不是国家卖的**：远航计划是真实公共工程（45 年建设史、学校参观、工程直播皆真）。密约只控制四个阀门——资金（裴闻昼）、安保（卫寒川）、医疗监管（出生记录 / 隐私条款）、紧急状态解释权（紧急委员会专家席）+ 签名（章怀安）+ 知识（岑一苇）。他们只需在国家进入紧急状态时站在阀门旁；多数官员 / 军人以为自己在做医疗 / 安保 / 物流 / 航天 / 法律。
2. **国家在地球上，密约在船上**：若密约是国家本身就不必逃。"怕国际审判"成立的前提正是他们可被国家抛弃。后来地球配合国际调查、拼凑追捕舰队，恰证国家机器未整体犯罪——犯罪的是借机器的三十人。
3. **密约自己也被抽了一次丁**：不足两百人的网络，登船只给掌握船上必需节点的约三十人，其余留地球等死 / 断供 / 被审判。政权带走全部，派系只带走需要的——呼应全书计税方式：连密约内部也是十抽一。

## 江照雪的真实身份（要点）

- 密约创始人江远山的秘密女儿；母亲死于伪装成医疗事故的清洗。
- 被定制最纯净续生方案，126 岁无回声——稳定不是幸运，是有人把来源做到极致（黑暗真相见 `01` / `08-三` / 第二部第 37 章）。
- 家族不看好她（秘密所生、拒接受把初龄质当作家产、无安保派系、无回声使父亲只当她为干净样本）。
- 故事开头被安排在源民区妇幼中心夜班分型医师——有专业无真权，既不会惹事也有利用价值。
- 软权力（姓氏门禁 / 临床权威 / 人脉 / 被聆听资格）有，硬权力（配额 / 安保 / 资金）无："能走进任何房间，但房间里的人可以不回答。"
- 她开场即已在私密调查家族与政权；秦砺不是怀疑起点，只是给了她冷链那一端。
- 登船方式与终点状态见 `01` 与 `09-〇`（天穹安保承包商身份、安检线重逢、船上卧底位置）。
