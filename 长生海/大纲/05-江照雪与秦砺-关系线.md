# 江照雪与秦砺：恋人关系线

> 人物档案见 `01-核心人物`；章节交叉见 `09-人物线索总表`。本文件只写两人关系的情感弧与权力规则。

## 关系核心

> 她把"让人活下去"当作爱；他把"谁有权决定我怎样活"当作自由。

两人不是富家女爱上底层男孩。他们站在长生制度最痛的两端：江照雪每次想给秦砺续命，面对的都是一个孩子本该带进自己人生的初龄储备（原理见 `00-初龄质`）。

## 四个阶段

1. **互为证据（秦望病房相识）**：互相使用，先交换冷链编号与病例权限。吸引来自秦砺第一次不把她当无瑕权威，直接指出她说"病人"时忘了病人还有母亲、债务、婚约和一个本想出生的孩子。
2. **时间不平等（她坦白 126 岁）**：他第一反应应是愤怒——"你见过的一百年比我可能剩下的全部还长，你凭什么说理解我着急"。真正靠近发生在她为他放弃一份安全内部报告、他第一次把能卖钱的资料完整交给她。相爱时不承诺永远，只承诺不替对方决定。
3. **未经同意的救命（港区冲突后）**：她在他失去意识时给了一剂来自不足十小时新生儿的续生微剂。这不是无私，是她第一次以爱之名复制父辈逻辑。他醒来从记录得知真相，愤怒的不是"宁愿死"而是"没让他承担选择的重量"。关系必须断裂，仍相爱但不互信。
4. **下一剂（第二部高潮）**：江照雪有权调配，却须从刚出生的孩子取走峰值；秦砺想活也知意味着什么。船上的病人会指责他自私。她第一次真正做到：即使失去他，也不再替他决定。

## 关系中的权力规则

1. 江照雪不能用资源 / 资格 / 船票"购买"秦砺的爱。
2. 秦砺不能只做被拯救的象征，必须掌握威胁江家与委员会的证据，主动选择上船与留下什么。
3. 越权用药后，秦砺有权离开 / 公开 / 拒原谅；感情不能立刻替代后果。
4. 年龄差必须成争论与误解的内容，不被浪漫化。
5. 最终是否继续为恋人，由她能否尊重他的自由决定，而非由"他活没活"。

## 关键场景（章节索引）

- **病房门口（已写）**：他拦住她，不让"分型结果"安抚家属。
- **废弃气候塔**：她坦白年龄，他问她记不记得三十岁害怕什么。
- **港区急救 / 用药记录**：她签字注射；他醒来问"你救了我，还是把我变成他们一样的人"。
- **离港舷窗**：她交第二剂授权密钥，第一次把决定还他。
- **第二部下一剂**：孩子出生，十小时倒计时；她只问"你要我怎么做"。

## 终点方向

- 讨论稿 A（苦涩有希望）/ B（更黑暗）：保留为情感讨论，不再作候选结局。
- **第二版锁定（以本条为准）**：第 47 章秦砺**接受**第二剂——表面 B，实为第三条路：不是想活，是档案还差最后一程，明知故犯再当受益人，把这笔债记进档案；江照雪不按按钮，只问"你要我怎么做"。追捕舰队抵达、两档合流后，秦砺允许自己死（一生第一件完全为自己做的事）；江照雪在旁什么都不做，完成偿还，随后封存档案、执行寿限。爱情收束于"机器记录配额，只有爱记录一个人"。
