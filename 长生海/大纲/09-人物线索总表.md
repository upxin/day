# 人物线索总表（写作接线图）

> 人物档案见 `01-核心人物`；章节目录见 `02/03`。本表是写作时的"交叉 / 错峰 / 防崩"操作手册。**铁律：任何角色行动须在本表找到来路；信息只沿交叉点流动。若正文出现本表没有的交叉或信息传递，先改本表，再改正文。**

## 〇、已锁定条目（以本表为准）

1. **秦砺船票**：用源场名单 + 街区信任 + 供应链不可替代性迫使委员会接受正式居民；江照雪第 24 章改名单只是执行层操作 + 私事（交密钥）。船票是他挣的，密钥是她给的，分开写。
2. **港区规模**：第 23 章"封锁—冲击—开枪"级，死亡个位数到十余，须有一名前文有名的源民人物死（建议 13 或 22 章先立）。不写屠杀级（会逼第二部通信线写不下去）。卫寒川条目"港区屠杀"一律按此规模。
3. **注射种姓**：仅 130 人有资格（30 密约上层 + 100 天穹安保），注射是投名状；其余 4670 不注射。秦砺不在 130 内，每剂皆走私。
4. **江照雪登船**：发射窗口完成证据人肉交接（活人不走信号），让出医疗总监席位，以天穹安保承包商登最后一班接驳船（江远山暗中安排）。安检线重逢。
5. **结局**：无审判。舰队迟到 60-80 年，抵达时罪行已长成国家，唯完成档案合流。秦砺先死（一生第一件完全为自己做的事），江照雪封存档案后执行寿限。数百年后江远山解密写"以下由被记录者补充"。裴闻昼至死不悔。
6. **核泄漏层**：白潮早核泄漏约两年；泄漏前五个月基层医师上报后删底稿；半真半假（地震真 / 维护削减人为）；别国真泄漏在先使移民话语合法。详见 `04/08`。
7. **坐标销毁与政要科学家入列**：三十人核心含章怀安（签名）与岑一苇（知识）；离港数小时岑一苇启动预埋程序销毁坐标（章怀安授权，弥生服从规则）；船多国共建，三十人偷走；重寻靠公共记忆。

## 一、人物线索引（详档见 `01`，节点见 `02/03`）

- **秦砺**（主角，全书不断线）：冷链配送员 → 证人 → 名单变量。五棒接力活下去理由见 `01`。第二部：计数 → 记忆馆发现 → 公开双轨账本 → 第二剂 → 允许自己死。
- **江照雪**（主角，上升线）：夜班分型医师 → 三次上升 → 让位登船。未结清：与父未清算 / 越权用药裂痕 / 自身供应真相 / 混源裂解风险。第二部：发现父投票权 → 看穿孕育配给 → 接收秦砺寄还证据 → 提替代方案 → 不按按钮。
- **秦望**（引线，死 20 章）：第一块多米诺。需至少两场清醒对手戏（想要什么 / 知道多少）；死在哥哥被支开时，触发秦砺急性发作。母亲下落 22-24 章交代（建议拒离街区）。
- **程见微**（纸面证据）：登记所审计员。取灰名单 → 发现公开名单会致清洗 → 托付陆以衡 → 认出摆渡人签批 → 留地球组证体。
- **沈未央**（记忆）：270 岁记忆修复师。记忆不可靠主题 → 疑被校准 → 认出摆渡人第一重 → 交原始记忆留地球。第一部结清（故意）。
- **陆以衡**（公共空间）：公益律师。听证公布灰名单 → 组织抗议 → 拒登船。"你们凭什么先走"无答，江照雪让位是迟到回答。
- **江远山**（父辈）：180 岁，三重裂解，密约创始人。第一部不正面超三次，力量在被谈论。第二部：回声被当投票权 → 早期模型曝光 → 数百年后忏悔（罪的红利吃完才忏悔）。
- **裴闻昼**（制度辩护）：至死不认制度吃人，只认"供应链瑕疵"。不可给悔悟戏。
- **卫寒川**（武力）：安保实际控制人。每次动手前台词"如果我不做会更糟"且在其信息里成立。活不到忏悔（战时人格烧掉他）。
- **章怀安**（政要）：142 岁，紧急委副主座，唯一公开政要。回答"为何看起来合法"——每步有合法签名。最积极推动逃亡（真相公开他先上审判席）。
- **岑一苇**（科学家）：91 岁，导航首席，工程明星。不为长生为"人类定居不能被法庭毁掉"。离港数小时销毁坐标。是否忏悔待定，建议最分裂。
- **摆渡人**（小 boss，止第一部）：约 215 岁，批次零，三段人生。明线药库老头 / 清场顾问；暗线三步骤揭穿（眼熟 → 签批 → 记忆）21-23 合流；暴露后断供速老（全书首次具象化断供）。详设见 `01`。
- **弥生**（AI）：永不破规则，只人能改写。权限规则：单域内任意关联，跨受保护域（出生 × 续生）须人类合法授权。"成长"是把规则解释到极限。第二部 39 章唯一一次主动呈交（须建立在合法授权上）。

## 五、防崩检查清单（每写完一章过一遍）

1. 本章每个出场角色，上一次出场在哪章？超过 7 章没出场的人，本章是否至少被别人提起一次？
2. 本章传递的每条信息，传递路径在本表交叉点里是否存在？角色不能知道他没有渠道知道的事。
3. 本章的交叉是否至少改变了一个人的状态？没改变的同场是废场，删或合并。
4. 本章是否有线到达峰值？是否只有一条？与上一峰值是否类型交替？
5. 秦砺的船票逻辑：他做的是否在"挣"，而不是"被安排"？
6. 江照雪是否又用了权限替别人做决定？（20 章之后，这是她的禁区，每次触碰都必须被她自己意识到。）
7. 弥生是否破规则了？（永不允许。只允许人改规则。）
8. 摆渡人揭穿三步骤的顺序是否还完好？
9. 江照雪供应线的真相是否泄露过早？（37 章前，连暗示都只能指向"来源隐秘"，不能指向"来源是具体的孩子"。）
10. 新出现的角色是否有主线功能？没有功能的肌理人物可以有（防"世界太功能化"），但**不能超过两条同时新增**，且必须附着在某条主线的生活面上。
11. **密约 ≠ 国家**：本章的船票、封控或泄漏是否被写成了"政府的意志"？（永不允许。永远是三十个人站在阀门旁边；多数执行者以为自己在做医疗、治安、物流、航天或法律工作。）
12. **注射种姓**：本章是否让 130 人之外的角色获得了官方注射？（永不允许。秦砺的每一剂只能来自江照雪的走私。）
13. **残忍的呈现方式**：涉及十抽一的内容是否用了白描场面？（除一个有名有姓的孩子外，一律用制度语言与对不上的数字。）
