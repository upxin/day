# 长生海前史与伏笔

> 详细时间线见 `00-项目总纲`（长生海为何早已存在）与 `08-密约编年史`（逐年锚点）。本文件只留写作所需的伏笔设计与硬规则，避免重复。

## 飞船建设时间线（摘要）

- -45 槐星确认 → -42 远航计划立项 → -36 L5 开工 → -28 人工海注水 → -20 封闭生态试验 → -8 首批深空测试 → 0 白潮爆发、临近发射。
- 各节点细节与公众记忆作用见 `00`；预留源场区见 `08` 第六节 / 第二部第 36 章。

## 核泄漏：白潮的定性盖子

> 白潮官方口径分两代：早期"基因/环境/菌群/气候"时代病，重采期末期升级为核泄漏。核泄漏同时是假病因、圈地理由、移民话语源头。

- 时间线见 `00-公众认知` 与 `08-编年史·爆发前夜`（-3 至 -1.5）。
- **删报告事件（04 独有伏笔）**：故事前约一年半，基层疾控医师上报异常聚集，泄漏后他亲手删底稿——"杀死真相的不是灭口，是一个合理的解释出现得太及时"。全书唯一在辐射落地前见过白潮的体制内证人，证据是他自己删的。留到后期翻出。

### 写作要点（核泄漏层）

1. 半真半假：每个签字人都只说得出自己那一笔——现代官僚系统的可辩解性。
2. 两年时间差是定时炸弹：最早死亡在辐射落地之前，因果倒置，是江照雪与程见微能撬动的最锋利杠杆（时间线证伪）。
3. 国际维度（别国、难民、审判）只作远处背景压力，不写具体——精密感来自密约藏在本国系统缝隙里。

## 坐标销毁（离港当日）

- 机制见 `00` 与 `08-二点五`：多国共建、三十人偷走；岑一苇预埋程序、章怀安授权；重寻靠公共记忆。
- **伏笔落点（04 独有）**：第 2 章帆阵测试新闻、第 4 章港区之行中，岑一苇以工程明星出镜——他后来的背叛是对公共记忆的背叛。

## 如何在第一部埋飞船伏笔

- **第二章·它在天上**：秦砺生日新闻庆祝帆阵展开，对源民区像天上豪宅。
- **第四章·他到过港区**：冷链订单进轨道港，只看见工程/安检/货柜/劳工，别立刻写成希望。
- **第九章·富人谈名单**：江家晚宴露出"谁有资格去未来"的阶层语言与回声人格。
- **第十八章·它变成门**：白潮后提前发射，社会发现船装不下要逃的人。
- **第二十四章·它有第二套设计**：江照雪发现船上预留人工孕育舱与出生登记所。

## 写作硬规则

1. 长生海前十五章只作远处公共工程 / 工作现场 / 阶级象征，不抢白潮与人物关系主戏。
2. 每次出现都比上一次离普通人更近：天上 → 港区 → 名单 → 门禁 → 离港。
3. 飞船有容量 / 航程 / 工程史 / 公众记忆，离港不是作者临时开的门。
4. 人工孕育舱始终是合理医疗设备，被用于源场是人的选择，非设备邪恶。
5. 第二部冲突从第一部未结清的名单 / 证据 / 死亡 / 爱里长出，不靠新怪物。
6. 核泄漏层只走背景音 / 新闻 / 证件语言，第一部不正面解释；读者第二部对账戏才回头看懂。
