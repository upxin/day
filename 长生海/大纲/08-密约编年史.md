# 《长生海》重构版：密约编年史

> 世界观机制见 `00`；密约政治逻辑见 `07`；航行账本（十抽一 / 注射种姓 / 冻存衰变）见 `00` 与 `03`；摆渡人详设见 `01`；江照雪黑暗真相见 `01` 与第二部第 37 章；写作纪律见 `09-防崩清单`。本文件只留：白潮为何现在爆发的总逻辑、编年史逐年锚点、与既有大纲的校准索引、可埋伏笔点。

## 一、总逻辑：白潮为什么是现在

> 初龄质采集已持续上百年，白潮偏偏在故事开始时爆发，因为**采集不是一直这么狠的**——它是剂量逐代递增后，账单第一次被压缩到一代人眼前。年份以故事元年（秦砺 30 岁、白潮爆发）为 0，向前为负。

| 阶段 | 年份 | 采集方式 | 受害一代下场 | 公众看到 |
|---|---|---|---|---|
| 实验期 | -135~-95 | 战时孤儿 / 难民营 / 无记录人群 | 无人追踪，混入战争死亡 | 无 |
| 低剂量期 | -60~-35 | "适应性校准"常规，6-10h 窗口微量 | 生育下降、45-55 岁死于"现代慢性病" | 寿命缩短读成时代病 |
| 替代工程失败 | -50~-35 | 人工孕育批量替代 | 低活性 / 加重裂解，废弃 | 无 |
| 重采期 | -35~0 | 窗口前移 0-2/2-6h，剂量数倍，集中源民区 | 50%-70% 于 28-36 岁死于多器官失调 | 白潮浮出 |

关键点：①早期死亡被"摊薄"成中年慢性病，旧口径勉强成立；②重采期把死亡压进 28-36 岁，密集同龄成片，捂不住；③剂量上调因三压叠加（成员老化 / 混源裂解 / 替代失败 + 出生率降）；④灰名单是密约的剂量校准监测表，也是程见微能找到它的理由。

## 二、编年史正文（逐年锚点）

### 前初龄质时代（-200 以前）

- 公开医学已实现有限延寿（数十年级），代价是神经 / 记忆需反复"校准"。沈未央（-270 生）是旧技术线受益者，活过整个初龄质时代，记得制度建立前的世界——密约反复校准她记忆的原因：她不是患者，是前朝遗物。

### 第九候选体：发现的起源（约 -191 至 -180）

- 深空生物观测网早于密约，针对若干"候选宜居行星"的秘密探测。第九候选体（后槐星）观测最长：到江远山接触时已积累 118 当地年、三代研究员记录。
- 约 -191（江远山约 23 岁）：与麦禾复核长喉兽行为——成年个体在幼体出生后十小时内吞食部分幼体，超窗口停止；被吞食者寿命同类 3-4 倍。他提出假说：这是所有经历出生的物种共有、仅出生后极短窗口存在的一份"初龄储备"。
- 立项申请题目刻意平淡——"新生个体组织中不可再生成分的分离与人体样本比对研究"。批注：批准。
- 约 -180（十一年后）：人体脐带血确认同源复合物，峰值出生后 0-2h，10h 后不可检出——**初龄质**得名。理论确认早于任何大规模人体提取。
- 此后四十余年被搁置——不是没人想用，是还没足够绝望的借口。战争与医疗崩溃在四十多年后提供借口。
- 这是他三重回声里最深羞愧的源头：不是后来难民营签的命令，是更早面对一种动物、第一次把念头写成"无聊"立项申请。笔下停了半秒——他没去想，后来也没再想起。

### 实验期（-135 至 -95）

- 战争与医疗崩溃。裴闻昼（-187）、江远山（-180）、卫寒川（-173）亲历大量本可避免早死，形成"延长生命永远正确"的信念。
- 军方医学项目在难民营 / 孤儿群首次将第九候选体原理大规模用于活体人，确认两限制：仅出生后十小时内高效提取、无法人工合成。**用的正是江远山二十多岁写进申请书的那套原理**——从提假说的年轻研究员到签超量采集命令的人，是同一个人两个年纪。
- 早期实验无伦理框架。锁定：江远山亲自签署过第一份对活体新生儿超量采集命令。
- 江照雪母亲作为临床研究员进入项目（约 -120 前后）。

#### 批次零：不成熟技术的第一批使用者

- 剂量摸索期（-130~-115）：在难民孤儿身上试剂量 / 窗口 / 回输，大多没活过实验期，少数成最深秘密。
- 第一批受益者（-120~-100）：战时高层 / 军官 / 金主插队先用不成熟技术，吞下代价——早期纯度低 / 来源杂 / 无稳定方案，相当比例出现严重自我分裂。当时无"回声人格"说法，军医写"多重人格，不可逆"。
- **这就是续生裂解的起源**：从第一天就写在技术里的缺陷，百年"改进"只是把发作从几年推迟到几十年、把症状驯化成"另一种工作状态"。密约对这词的粉饰史 = 副作用管理史。
- 第一批受益者中有人死于裂解失控、有人被处理，极少数成活最老幽灵——**摆渡人即其中之一**（详见 `01`）。
- 江远山三层裂解源于此期：他是第一批受益者里职位最高、活得最久、管理最好者，"管理得好"是他后来权力的信用来源。

### 江照雪的出生与母亲的死（-126 至 -110）

- -126：江照雪出生，秘密。江远山为她定制最纯净方案（单一来源 / 极早期窗口 / 低频次 / 终生专线），成"无回声者"——稳定不是幸运，是有人把来源做到极致。
- 约 -110：母亲发现采集真相或试图退出，死于伪装成医疗事故的清洗。江远山保住女儿没保母亲，是第一道裂缝，也是"保护即囚禁"模式起点。

### 密约成形（-95 至 -74）

- 稀缺性决定初龄质不可能公开分享。掌握提纯 / 医院 / 资金 / 安保 / 媒体的几十人形成以配额 / 人情 / 把柄咬合的秘密网络（不超两百人）。规则：不共享来源只交易配额；断供即死；身份可伪造脸不能久留。
- -74：江远山公开"死亡"，转假身份经营轨道安保与远航投资。密约完成从战时项目残余到影子网络的转型。

### 制度化低剂量期（-60 至 -35）

- "适应性校准"成常规产科程序，公开理由免疫定标 / 筛查，实际微量、6-10h 窗口，伤害真实但缓慢可辩解。
- 空间原则：**核心区轻采 / 不采，源民区重点采**——阶级分布是设计不是结果。
- 此代被采者（故事开始时 35-60 岁）表现为生育偏低 / 中年慢性病，旧口径恰好成立。
- 沈未央在此期间目睹源民抗议与孩子被带走，后被多次校准到无法确认真伪。

### 替代工程（-50 至 -35，失败）

- 尝试人工子宫批量孕育建工业化来源，失败：移植给成人活性低 / 匹配差 / 加重裂解。外围成员试药者出现严重裂解，成内部旧账。
- 后果：确认自然妊娠来源不可替代（需求只增不减）；人工孕育舱技术转民用与航天储备——四十年后以"星际定居设备"装上长生海，等着重启用。

### 长生海与源场预留（-45 至 -35）

- -45：确认槐星宜居。对公众是目的地；对密约是地球管不到的供应场——远航尚未立项，密约内部已在讨论。
- -42：远航公开立项，密约以个人基金 / 旧军方关系 / 安保合同提供部分预算（远见，非慈善）。内部模型已算地球采集逼近极限。
- -36：L5 开工，建造初期即预留独立医疗区 / 人工孕育舱位 / 出生登记空间（沈未央旧记忆、第二部第 36 章指向）。探索船与出生供应链不是后来才结合。

### 重采期（-35 至 0）——白潮引信

- 配额战争升级：成员老化 / 混源裂解 / 替代失败 / 出生率降，四头挤压。应对向内加码——窗口系统性前移（0-2h 成高阶标准），单婴数倍，集中源民区。
- 重采期首批孩子生于约 -35~-30。**秦砺（-30 生）与秦望即重采期孩子**。秦望档案被挖空的四十八小时，即典型早期窗口高量采集。
- 配套掩盖同步升级：十小时记录封存条款、出生档案批量挖空、"新世代适应性低反应综合征"等病名储备——重采期开工就预装好的消音器。
- **核泄漏预案是消音器终极形态**：重采期末期模型算出稀释效应将消失、旧口径必破。他们不制造灾难只准备——选沿海老核电站，维护预算连续三年"被削减"，等地震多发年代强震。地震真，泄漏可防，他们只是没关窗。
- 约 -15 起，重采期首批进育龄，不孕 / 早衰成片；"活不过三十五岁"说法由来。官方仍用低剂量旧口径拖延（两代混居，曲线被稀释）。

### 爆发前夜：两年提前量（-3 至 -1.5）

- 约 -3：白潮小规模爆发，源民边缘、症状散，归入旧口径，无新闻资格。
- 泄漏前五个月：基层疾控医师上报异常聚集，走完流程本应复核。
- 约 -1.5：强震，老核电站泄漏。应急接管，异常"有解释"。医师看自己五个月前报告，松口气亲手删底稿——天灾替他灭口，他还感激（细节与伏笔见 `04`）。
- 此前约一年（约 -4~-2.5）：别国核电站已真泄漏，难民潮使"移民"话语先合法化。
- 此后：白潮症状全读成低剂量辐射病。**最早死亡死在辐射落地之前**——因果倒置，第一部最锋利证据线（时间线证伪）。

### 爆发（0 年）

- 重采期主体 cohort 抵 28-36 岁死亡窗口，死亡密集同龄同城同街区，稀释消失，白潮浮出。故事开始。

## 二点五、航行期账本与追捕舰队锚点

- 冻存衰变 / 十抽一 / 注射种姓 130 人 / 离港前库存填补：数值与推算见 `00-世界机制` 与 `03-第二部`（含秦砺不在 130 内、每剂皆走私）。

## 三、江照雪供应链黑暗真相（落点）

她的"无回声"是最干净一张脸、最脏一条链：方案为单一来源 / 极早期窗口 / 终生专线，每剂来自出生后两小时内被超量采集的自然妊娠新生儿。叙事功能：第一部只给到"来源最隐秘"，完整真相留第二部第 37 章——**发现者改为秦砺**，在父亲早期预测模型证据旁看见供应记录接收端"江照雪"三字；他不写评判，只把证据原件附进档案寄还她。她反制度的合法性不再干净。详见 `01` 与该章。

## 六、衍生人物：摆渡人（详见 `01-核心人物`）

核心：活二百多年、只换三次身份，故事不同时间层的三个"不同的人"是同一个人。三段人生（战时军医 / 档案官员 / 药库老头）、反转三步骤（眼熟 → 签批 → 记忆）、终局断供速老——完整设定见 `01`。本章只补：他的存在修复"初龄质已采百年为何白潮现在爆发"的叙事齿轮（他是百年掩盖链的活档案）。
