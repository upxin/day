# 《长生海》第一部叙事重心与决定链

> **用途：** 本文件只裁决“读者跟随谁理解世界、主流程由谁作出选择、后果由谁带进下一章”。章节事件仍以《长生海_第一部章节目录》为准，数字仍以《长生海_数字与时间正典》为准。
>
> **核心原则：** 读者最爱谁，与读者活在谁的视角里、追随谁的选择，是两条不同的轴。

## 一、两条轴

### 1. 情感吸引轴

程野可以是全书最讨人喜欢的人。林微、周艾、孟响、乔伊、许澄也必须拥有不依赖主角注视的生活、职业、爱情、笑话和选择。

这些章节负责回答：**这个世界有什么值得失去。**

配角有权决定自己的爱情、职业、冷冻与死亡，不得为了抬高主角而剥夺其人格。

### 2. 叙事引力轴

白雪与秦砺负责回答：**失去以后，人还要怎样理解、怎样负责、怎样继续选择。**

- 白雪垄断制度内部的信息入口：申请、病例、权限、风险模型、库存、父亲档案与医学资源。
- 秦砺垄断具体人生的信息入口：姓名、口述、急诊、死亡确认、证据边界、沉睡记录与档案空白。
- 白远山、韩缜、纳赛尔和雷蒙德可以拥有改变历史的决定，但他们的选择必须成为白雪与秦砺在现实时间里承受、反驳或继承的后果。
- 程野可以提供最大的悲伤，却不掌握核心秘密，不决定灾难后的制度方向，也不承担全书最后的问题。

## 二、两名主角各自的独立发动机

### 白雪：正确决定也会伤人

她的主角性不依赖程野死亡。

驳回李承济十二例申请 → 再次签署“现阶段无证据关联” → 李晓的死亡证明成为她要求的新增证据 → 关闭秦砺接口 → 知道初龄质来源后仍批准救人 → 公开父亲资料时同时公开自己的签名。

她从“相信系统能替选择划清责任”，走到“系统可以提供理由，不能替签名者承担代价”。

### 秦砺：被看见不天然等于被保护

他的主角性不依赖替程野复仇。

为普通人记录愿望 → 用医生信用宣传生命底图 → 面对母亲口述仍标记证据边界 → 不把死者写成英雄 → 被逃离城市的父亲认出宣传片 → 在真相公开时先公开自己的旧说明 → 尊重许澄拒绝冷冻并承担疑问 → 最终为离线聚落留下坐标空白。

他从“记录越完整越接近正义”，走到“记录也可能成为权力的入口；有些空白是责任”。

## 四、后续写作检查表

每写完一章，必须回答：

1. 本章最可爱、最痛的人是谁？这可以不是主角。
2. 本章谁获得了改变理解方式的新信息？关键入口应回到白雪或秦砺。
3. 本章谁作出会改变后续路径的决定？若不是白雪或秦砺，后果必须明确进入二人的选择线。
4. 配角是否仍在替自己作个人决定，而不是被主角当作伦理道具？
5. 白雪是否又在用一个合理理由分配损失？秦砺是否又在决定什么该写、怎样写、或不该写？
6. 这次选择的代价有没有在后续至少再出现一次？如果没有，它还不是人物弧线，只是情节动作。
