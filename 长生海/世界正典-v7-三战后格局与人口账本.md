# 《长生海》世界正典 v7：三战后格局与人口账本

> 状态：作者核账文件。世界格局、人口总量、年度出生与续生供需以本文件为准；正文只选择与人物当天生活有关的部分呈现。

## 一、第三次世界战争

第三次世界战争发生于2041—2048年。战争不是由现实中的某一个国家单独发动，也没有一个可以继承旧世界全部权力的胜利者。气候迁徙、粮食与淡水危机、轨道资源竞争和自主武器误判使数个政治—经济集团先后进入战争；轨道封锁、基础设施攻击、有限核打击与随后的饥荒和疫病共同造成主要人口损失。

2048年的停火不是大团圆。各集团只是同时失去继续战争的工业与人口能力。战后世界把三件事视为不能再完全交给单一国家的共同风险：大规模杀伤性武器、近地轨道与深空设施、跨境生命技术。

同年，联合清理队在一处被战争和地质活动共同撕开的古代遗址下发现远古外星飞船残骸。遗星发现没有结束战争，也没有立刻统一人类；它首先被停火集团分别占有，后来才因任何一方都无法独立解译而成为有限合作的基础。

## 二、三战后的世界格局

### 1. 地球没有统一政府

战后形成若干区域共同体、自治城市网络、海洋聚居区和轨道居民区。它们保留自己的司法、福利、医院、家庭制度和数据主权。正文不必列出完整世界地图，只需持续证明不同地区使用不同语言处理同一个问题：公共卫生、市场连续权、家庭自主、宗教禁令、国家安全或人口保全。

### 2. 三个跨域机构

- **地球协调议会：** 维护停火框架、轨道安全和少数跨境公约，没有直接接管各地区医院与产科的行政权。
- **人类深空联合署：** 管理遗星公开研究、恒星际工程和阿卡迪亚任务。成员来自不同共同体，预算与人员均受多方审计。
- **跨域医学法庭：** 审理超出单一区域边界的高风险人体项目，可以让公开医疗入口合法成立，却不能自动关闭所有地区、秘密项目和黑市。

这套结构解释三件事：遗星研究能够跨越数百年而不依赖一个永恒政权；白雪的红色警报能够切断主流认证、保险和运输，却不能一键关闭全球；阿卡迪亚能够代表一项跨文明工程，却不等于全人类已经形成单一意志。

### 3. 高风险生命决定采用四方联签

任何涉及新增初赋提取、全球暂停或跨域恢复的决定，都不能由一名“生物钥匙持有人”单独开启或关闭。公开体系固定拆成四个互不替代的责任栏：

1. **临床因果与必要性：** 由独立临床组确认风险阈值、受体病情与替代方案；
2. **数据完整性与追溯：** 由审计组确认病例、供体、材料和受体链没有被拆分或篡改；
3. **儿童利益与异议记录：** 由独立儿童利益代理确认不能表达者的风险、父母权限边界和反对意见已被永久保存；
4. **法律激活与范围：** 由跨域医学法庭或任务地临时宪章确认适用地区、剂量上限、期限和退出条件。

四栏同时完成，系统才改变公开默认规则。白雪在地球和C-9承担的是第二栏，并因本人受益关系公开回避受体排序；她的签名具有个人责任，却不是一人控制文明的开关。C-9政治议会还必须先通过具体名单，四方联签只负责让决定可以合法执行，不替代表决。

地球红色警报前，白雪因提交影子索引被调离原岗位。韩真交出降级文件、材料进入刑事保全后，跨域医学法庭才按单一案号任命她为独立数据证据保全人；授权只允许恢复供体号、材料流向和受体权益的关联，不赋予临床判断、受体排序或政策表决权，并在归档后自动失效。她登船后只是任务档案完整性审计员；C-9第二次联签必须由当地任务宪章基于新案号重新任命，不能把地球临时权限带到另一颗星球。

### 4. 繁荣与贫穷同时存在

三战后的自动化、能源和材料技术使基本生存成本显著下降，医疗与公共基础设施也远胜旧时代。繁荣是真的，但财产、居住空间、教育路径、身体风险和决定权仍然分配不均。

AI承担大量标准化生产、物流和维护，人类仍集中于照护、判断、现场修理、复杂协作、公共责任与创造性工作。许渡的维护岗位不是因为AI不会修管道，而是封闭生态和城市水网仍要求可以承担现场责任的人；陈澜当年接受供体补偿，也不是因为没有任何基础保障，而是因为住房、教育、医疗债务和阶层跃迁依然需要钱。

## 三、人口正典

人口下降不只来自战争死亡。战后长期辐射与环境损伤、迁徙、低生育、晚婚晚育、自动化社会中的个人生活选择和生态配额共同作用，使人口在繁荣恢复以后仍继续缓慢下降。

| 年代 | 全球人口作者口径 | 叙事意义 |
|---|---:|---|
| 2040年，三战前夕 | 约98亿 | 旧世界人口峰值附近。 |
| 2048年，停火 | 约71亿 | 战争直接损失已经发生，次生灾难尚未结束。 |
| 2075年 | 约36亿 | 饥荒、疫病、污染与出生断层完成第二次人口下坠。 |
| 2140年 | 约25亿 | 重建完成，人口下降转为缓慢、制度化趋势。 |
| 2240年代，遗星公开 | 约17亿 | 全球互联与技术繁荣形成，但不再追求恢复旧人口峰值。 |
| 2306年，T-42续生扩大 | 约14.8亿 | 供体制度进入规模化阶段。 |
| 2318年，T-30健康停龄标准化 | 约14.6亿 | 不是首次扩大；滚动救治已经运行十二年，健康使用与年度连续权在此后制度化。 |
| 2341年，T-7风险异常 | 约14.2亿 | 年度出生约810万，人口仍在缓慢下降。 |
| 2348年，T-0发射 | 约13.8亿 | 白潮与生育恐慌使年度出生降至约670万。 |

十三点八亿不是濒临灭绝的人类。城市、贫困、阶层、跨境市场、文化差异和全球工程都仍然存在；真正危险是一个本已低生育的文明，又失去数百万处于生育、照护和技术承接年龄的青年。

## 四、阿卡迪亚工程边界

- 真正的阿卡迪亚主舰在地月高轨与月地拉格朗日联合船坞分段组装，不在地面完整建造。
- 各地“发射城”是全尺寸生活验证片区、乘员城市、模块工厂和轨道运输节点。地面街区采用与主舰相同的水网、生态、医疗和控制接口，但不会随船起飞。
- T-19主居住环高轨合龙，只代表城市骨架闭合；推进阵列、辐射防护、工业母机和封闭生态仍需十九年完成。
- T-0“发射”指主舰脱离高轨船坞并进入日地离场轨道。主推进在远离地月空间后逐级加速，不从地面直接以恒星际推力起飞。
- 许渡在地面验证片区工作，故障数据会直接决定对应轨道模块能否验收；这解释他既参与阿卡迪亚，又不需要每天往返高轨。
- 阿卡迪亚携带可在目的地展开的大口径相干光阵列；太阳系在T-0以前已建成月背—外太阳系分布式接收网，长期锁定C-9并预存星历、编码和窄接收窗口。它只能恢复约定方向的高功率数据包，不能提供实时通信或接收任意弱信号；C-9至地球单程仍需十五点二年。

## 五、续生供需账本

### 1. 年度流量

- 健康续生者每十二个月需要一次标准注射。
- 白潮患者使用同一标准当量只能获得递减的桥接期，不能套用健康停龄的固定一年：早期可能稳定九至十个月，重症期常缩短至半年左右，并可能需要追加。
- T-3限制开始以前，公开体系每年约产生四十七万个标准当量；秘密项目和无法核账的市场估计另有八万至十三万个。
- 高峰年度总流量约五十五万至六十万个标准当量。
- 全球登记长期续生者约四十一万，每年消耗约四十一万个标准当量；其余流向终末救治、白潮桥接、事故急救、试验损耗与库存。
- 在年度出生约七百万至八百万的阶段，公开与秘密提取合计涉及约7%—9%的新生儿。它足以形成遍布全球的一代受害者，却不是“每个婴儿都被抽取”。

### 2. 许渡个人剂量账

- **A剂量，T-6：** 一个公开库存标准当量，第一次全身失稳时使用，稳定约九至十个月。
- **B剂量，T-3：** 一个公开库存标准当量，越过不可逆阈值后使用，明显稳定约六个月，此后只能减慢。
- **C剂量，T-2至T-1：** 半个标准当量，来自红色警报前已入库批次，作为最后一次姑息桥接，延缓约四个月。
- 许渡累计使用二点五个标准当量，均在其个人决定前已经提取，无法返还供体。他撤回的是从下一年度起至少每年一个单位、病程加重时追加的新增连续授权。
- “一个婴儿给健康成人约一年”仍是标准换算；不能据此写成一个单位必然让重症白潮患者多活整整一年。

### 3. 累计供体

- 公开体系累计登记供体约一千二百六十万人，其中约八百四十万属于标准或高剂量队列。
- 秘密项目、黑市与记录缺失者估计另有一百八十万至三百二十万人。
- 这一区间不能在正文中被补成精确数字。黑市有意不保留供体反向键，雷蒙德在T-4后更把“无终身反查”设为下游合同的溢价条件。因此真相公开后，一部分成年人无法确认自己出生时是否被提取；这种不确定性是黑市真实制造的伤害，不是作者数学疏漏。
- 雷蒙德在红色警报后为自己取得的那一份新剂量归入秘密项目、黑市与记录缺失区间，不改变公开库存和阿卡迪亚二万二千个标准当量的账本。
- 标准与高剂量登记供体中，预计约四百二十万至五百九十万人会在三十至四十岁进入不同程度白潮；秘密队列使真实上限无法确定。

白潮因此是全球性代际危机，但不是数年内杀死全人类的末日病毒。它摧毁的是青年人口结构、出生信任和社会接力能力；人口真正的崩盘风险来自此后数十年的低出生与代际断层。

### 4. 阿卡迪亚账本

- 发射人口四万八千，其中约四万零四百名为原定任务人员、定居者与家属，七千六百个弹性席位在白潮后重编。
- 雷蒙德计入七千六百个重编席位中的高剂量纵向样本，但身份是跨域羁押转移的待审人员，不是普通移民；他没有船内表决权、任务权限和自由公共接口。
- 船上装载二万二千个标准当量；十年航程计划消耗约八千八百，抵达时余约一万三千二百。
- C-9复温、取样和跨物种适配使年均消耗升至约三千三百，现场冗余约四年。
- 库存耗尽后批准的四十八例、后来累计的一百七十三例，均按“一名供体—一个标准当量—一次具体操作”核算。材料只提供复温、手术或器官重建的短期复稳窗口；常规治疗成功者退出初赋队列，失败者仍可能死亡，任何人都不因一次获批自动取得年度续针权。
- 因此，一百七十三个单位不是用来让一百七十三名重症患者连续生活三至四年，也不承担原本每年三千三百单位的总消耗。库存归零后，绝大多数健康使用者自然衰老，多数非紧急依赖者继续低温、放弃治疗或死亡；新增单位只对应一百七十三次被逐案批准的高风险操作。
- 飞船封闭生态的稳定活动人口上限为六万，紧急短期上限约六万六千；五千二百名低代谢者使航程初期负荷低于名义人口。

## 六、写作边界

1. 三战是世界形成原因，不是另一部战争小说。正文通过遗址、人口年龄、跨域机构和仍未修复的区域差异呈现，不连续补写战争编年史。
2. 不使用现实国家名称承担唯一反派功能，也不把所有制度写成同一种政治结构。
3. 不写成战后贫穷废土。许渡生活在真实繁荣中，贫困表现为机会、住房、债务和风险分配，而不是所有人都缺少食物。
4. 不把人口下降写成某个全球政府成功执行的单一强制计划。不同地区既有生态配额、福利鼓励、市场放任，也有家庭自主与地方强制。
5. 人口数字只负责核账。正文优先写空下来的教室、延后的怀孕、病房年龄倒置和家庭是否还敢把孩子交给产科。
